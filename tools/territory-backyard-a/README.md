# 新手領地後院：本機展示

依 `docs/execution/2026-10-31/01-A-territory-backyard.md` 第 6 節：走進後院，在兩塊田種青靈草或淨水蓮，快轉看四個生長階段，收成後院角的守燈亮一段，最多亮到 4 段。柴門可以開關；收成後，晾藥架會掛上草藥。

```powershell
cd tools/territory-backyard-a; npm ci; npm test; npm start   # http://127.0.0.1:4183
```

## 操作

| 動作 | 鍵盤滑鼠 | 觸控（橫向） |
|---|---|---|
| 移動 | WASD | 左下搖桿 |
| 轉視角 | 拖曳 | 右半邊拖曳 |

## 規則（`yard.mjs`，測試在 `yard.test.mjs`）

- **生長階段**：照工作包的門檻，`t < 0.25` 嫩芽（浮葉）、`< 0.6` 幼株（立葉）、`< 1` 成株（花苞）、`>= 1` 成熟（開花）。
  - 展示裡 1 倍速 90 秒長成，快轉 30 倍約 3 秒。
- **收成**：只有成熟才能收。
  - 每次種下都有一個編號，同一個編號只算一次收成；連按、重送或舊編號都不會讓燈多亮。
- **守燈**：亮度 = 收成次數，上限 4。
  - 遊戲裡改由伺服器的「脈息」換算，換算方式由核心組決定。
  - 畫面上不說明燈為什麼會亮。
- **柴門**：玩家站在門板的擺動範圍內（門前後約 1 m）時不會關上，所以不會把人夾住或關在門裡；關上後擋住通道。
- **田的狀態**：
  - 空田是乾土。
  - 種下後換成濕土貼圖。
  - 種淨水蓮時再顯示積水。
- **展示不發正式資源**：種植、收成只存在本機記憶體裡，重新整理就重置。

## 實測（`capture.mjs`，真 Chromium、真按鍵）

```powershell
node capture.mjs --modules <裝了 playwright-core 的資料夾> --chrome <chrome.exe>
node record.mjs  --modules <同上> --chrome <chrome.exe>      # 錄影；再用 art/source/territory-backyard-a/encode_video.py 轉 MP4
```

最近一次的結果：
- 左田：青靈草四階段 → 收成 → 守燈從 0 變 1；連按兩次 E 只算一次。
- 右田：淨水蓮四階段 → 收成；再收三次後燈停在 4。
- 晾藥架在收成後掛滿草藥。
- 柴門：
  - 打開後走得出去，也走得回來。
  - 站在門口時按關門，門維持開著。
  - 退開後才關上；關上後走不過去。
- 主控台錯誤：桌面 0 個，手機橫向（844 × 390）0 個。

截圖在 `art/previews/territory-backyard-a/demo/`，短片是 `walkthrough_player_view.mp4`（31 秒）。
