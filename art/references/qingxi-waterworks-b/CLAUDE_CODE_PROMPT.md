## 2. 品質方向

風格：青溪村公共水工，舊石、木榫、銅箍，克制的苔痕與水漬；古樸、有使用痕跡、構造可信，維修後能看出水從哪裡來、往哪裡去。B01必須像公共工程起點，不能做成私人靈田床。

- 先把輪廓、比例、接合與操作尺度做對，再做大／中／小層次細節。石材有合理厚度、邊緣磨損與局部缺角；木材有端面、紋理方向與真正可辨識的榫接；銅箍有厚度、緊固點與局部氧化。不要靠隨機噪聲、到處撒裂縫或堆方塊充當精修。
- 拼接口必須平整、乾淨；磨損和苔蘚不能堵住接口或製造漏縫。水流、濕痕、木石銅材質要能在正常光照下分辨，不能用發光特效遮掩結構問題。
- 不得複製既有 irrigation-v2/water-channel 充數。既有資產最多作有來源標示的背景，不計入12件新件。
- 三視圖是概念圖，不是 CAD。優先順序：使用者用途及專案規則 → README 明確尺寸及 image-manifest 的修正說明 → 圖中輪廓／材質 → 其他裝飾。不要照抄 AI 圖的透視、封端、尺寸箭頭或互相矛盾的機械結構。日常幾何修正自行完成並記錄；缺少外部真實接口資料，只標記該依賴，繼續其他可做工作。

## 4. 尺度、接縫與活動機構

- 以公尺建模、metric scale=1；Blender Z-up、前方-Y；GLB使用正常匯出座標轉換。母稿與交換檔用已知標尺驗證，不能只改單位標籤。根節點統一底面中心；B10根節點用地面線，向下保留0.30 m埋土段；輪與閘板另有動作軸心。
- 共用槽口：外寬0.60 m、總高0.40 m、淨寬0.40 m、底厚0.10 m、左右壁厚各0.10 m；水深提案0.18 m，平放時水面Z=0.28 m。槽口端面與槽底必須連續，禁止封端石堵流。
- 20 mm墊片／凹槽只是參考提案：做一套可實際相接的裝配規則，記錄密封墊未壓縮／裝配尺寸及凹槽位置，不得兩側重複計入造成縫或疊面。測試目標：接口中心及底面誤差≤1 mm、面法線相反對齊；合理榫接／墊片嵌合單獨列明，不能以大面積穿插遮縫。
- 每個接口建立命名 socket/Empty，保存位置、法線、上方向、淨寬、底高與相容類型到 interfaces.json。至少驗證直—直、直—彎、直—三通、基座—直、閘板與槽段、閘輪與閘板。
- B05關閉貼槽底，不能保留圖片中看似可漏水的縫；B06輪軸、齒條與轉動方向一致。用實際齒輪半徑決定升程和轉角，避免輪空轉、齒條穿框。關閉、半開、全開都檢視。
- B08原圖主視姿態不同，統一成同一剛體幾何後重新出正交三視圖。B10承梁必須接觸槽底；高50 cm支撐不能直接插入地面路線製造無坡度的高程跳躍。
- 水體、可動部件、碰撞和裝飾分開命名。動畫使用可匯出的transform／骨架／morph並烘焙；Blender專用約束與材質節點不能假稱在GLB會自行運作。水流預覽可用Blender材質動畫，但須另外說明交換檔需要什麼引擎材質或驅動，並測試實際可攜動畫。

## 6. 驗證與完成標準

1. 先完成B01–B06及一條裝配路線，檢查並修正後再做B07–B12；這是工作順序，不是到第一批就停止等待批准。

3. 自動化驗證實際幾何：有限座標、退化面、重複／共面面、反法線、UV與材質、尺寸／原點／變換、面數、活動軸心、接口對齊、動畫範圍。實體件檢查非流形；水面／薄布等刻意開放面分組記錄，不一刀切誤報或忽略。

5. 每個GLB及實際交付FBX在乾淨Blender場景回匯；比較尺寸、材質貼圖、命名層級、可動軸與動畫。回匯後渲染，不能只檢查檔案存在。
