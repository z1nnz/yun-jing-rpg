# 青溪世界方向圖

這五張是使用者 2026-10-25 提供的規劃參考，不是遊戲截圖、可直接匯入的模型或逐像素重製目標。

| 圖 | 借用的空間語言 | 製作階段 |
|---|---|---|
| [1](world-vision-1.jpg) | 溪谷、小鎮、田地、橋與遠山宗門的層次 | 青溪首塊地區的主體 |
| [2](world-vision-2.jpg) | 高差山路、瀑布、峭壁棧道與山門 | 北側遠景；之後擴展 |
| [3](world-vision-3.jpg) | 湖面、遺跡、遠處浮島 | 之後的州域，不塞入新手村 |
| [4](world-vision-4.jpg) | 古樹村落、濕地、水道與洞口 | 首塊地區的生活感 |
| [5](world-vision-5.jpg) | 古樹廣場、溪谷橋、竹林和多層視線 | 首塊地區的主要構圖 |

本輪先做約 180 × 146 公尺的村落至東側林地切片。實際製作從可重用的房、松、竹、石、橋、峭壁和溪流模組拼起來；遠處宗門與大型瀑布保留為後續區域，不假裝這一張切片就是完整大世界。
