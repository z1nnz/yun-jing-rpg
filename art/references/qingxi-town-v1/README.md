## 圖中內容

- **中心：** 巨大古樹與樹下多層樓閣；樹前是有同心圓陣紋的圓形石廣場。
- **水系：** 前方是多層湖水和小瀑布，水面有荷葉，木棧道與小橋在水上曲折連通，沿路掛燈籠。
- **左側：** 竹林與燈籠小徑；左上山坡有古代石門遺跡、石階和瀑布。
- **右側：** 山壁洞窟透出暖光，有水車木屋、布篷市集攤位，以及籬笆圍起的菜田或藥田。
- **遠景：** 石灰岩奇峰，山上有宗門建築與瀑布；雲霧繚繞，晨光從左上方照入。
