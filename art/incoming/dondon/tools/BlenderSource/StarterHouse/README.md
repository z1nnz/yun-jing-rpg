# 青溪鎮新手民宅

修仙小鎮的一層民宅外觀原型，採暖白灰牆、深色木構、青灰筒瓦、石基與木前廊。可作主角初始住處，之後重用零件變化成雜貨鋪與其他民宅。

執行 `build_starter_house.py` 會在 `Models/StarterHouse/vNNN` 新建一版，既有模型不覆寫。以實際產生 `.blend` 的版本為準；中途失敗的版本資料夾可能為空。

## 可編輯的零件

| Blender 集合 | 內容 |
| --- | --- |
| 01_Foundation_Porch_Steps | 石砌地基、前廊板、3 階入口石階、資產總根節點 |
| 02_Plaster_Wall_Modules | 四面牆、山牆；門窗位置保留幾何開口 |
| 03_Timber_Frame | 梁柱、前廊支柱與斜撐 |
| 04_Curved_Tile_Roof | 屋頂底板、分條筒瓦、屋脊、簷口與椽木 |
| 05_Hinged_Double_Door | 左右門扇、門框、金屬門環、兩個門軸根節點 |
| 06_Lattice_Window_Modules | 5 組紙面格窗、木框與石窗台 |
| 07_Porch_Props | 長凳、2 個陶罐 |
| 90_Studio_Not_Exported | 預覽用地面、燈光與攝影機；不匯出到 FBX |

## 尺度與操作

- 1 單位 = 1 公尺，主體牆面範圍 7.2 × 5.2 公尺；前廊、屋簷和石階在此範圍之外。
- 地板高度 0.54 公尺，入口 3 階各高 0.18 公尺。
- 門洞寬 1.7 公尺、高 2.41 公尺，正面朝 Blender -Y。
- 移動 `StarterHouse_ROOT` 可移動整棟房屋；原點在地面中央。
- `Door_Left_Hinge`、`Door_Right_Hinge` 各自繞局部 Z 軸旋轉即可開門，已保留子物件結構；目前沒有動畫。
- 隱藏 `04_Curved_Tile_Roof` 可查看牆面開口與地板。
- 俯視與角色行走範圍仍需放入 Unity 後確認；本檔未取代前一版出生廣場。

## 交付與限制

每個成功版本包含 `.blend`、保留門軸階層的 `.fbx`、模型資料，以及正面右側、正面、背面左側的 3 張同模型渲染圖。

這是可編輯的外觀第一版，室內尚無家具與裝潢，也沒有碰撞網格、開門互動、LOD 或 UV／材質貼圖烘焙。程序材質在 FBX 中只有基礎色；Unity 內需要重建或烘焙材質。正式遊戲使用前需合併適當靜態零件並驗證效能。

下一步可先在出生廣場周邊配置這棟民宅，驗證人物與鏡頭尺度，再變化成鐵匠鋪；鐵匠鋪新增爐灶、鐵砧、工作台和武器架。
