# 八款破舊房屋（H01–H08）產生器計畫

參考：`art/references/qingxi-world-ruins-b/house-variants/H0x_*-v001.png`（使用者 2026-10-30 提供，含 .prompt.txt）。
基礎：`wr_scene_hut.py`（D3_AbandonedHut）。目標：一個參數化產生器 `wr_houses.py`，每款一組設定，
共用地基、框架、門、床、碰撞、走入檢查；不同的是牆體、屋頂形式、屋面材料、配色、破損位置。
每款仍是獨立資產 `H0x_<名稱>`，各自 model_info / validation / 四視圖 / 特寫，並和 D3 一樣可走入。

## 共用模組（要新增或通用化）
1. 破損遮罩：屋面座標 (x, s) 上的區域函式取代目前寫死的 `edge_front/edge_rear`；遮罩內瓦片消失、望板斷、椽子斷落。
2. 屋頂形式：雙坡（已有）、四坡（四個斜面，瓦／木瓦以斜脊線裁切）、脊沿 y、單坡側間。
3. 屋面：陶瓦（已有，換色）、木瓦片（平板疊鋪）、劈竹（半剖竹管交錯）、茅草（厚層＋垂邊＋壓竿）。
4. 牆體：灰泥框架（已有）、夯土整牆、竹編牆片、橫木板、石砌＋抹面。
5. 牆角崩落：移除區域內的柱／牆片，換成斷柱、土塊／石塊堆與碎木；碰撞跟著缺口改。
6. UV 實例化沿用（瓦、木瓦、劈竹、相同椽子），以提高貼圖密度。

## 驗收（每款）
尺寸在 D3 槽位 5.5 × 4.5 × 3.8 內、原點在占地中心、前方 -Y；門 ≥ 0.9 × 1.9、室內 2 × 2 m 淨空；
LOD1 ≈ 50%、LOD2 ≈ 15%；_Collision；四視圖＋特寫；自評 ≥ 95 才交付，未過就改。
參考圖 README 指出的問題（多餘箭、桶、籃筐）不照抄：屋內只放床架、空箭袋（沿用 D3 的故事物件只放在 D3）。
