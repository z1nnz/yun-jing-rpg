## Unity 匯入備註
- FBX 為 Y-up、-Z forward，已套用比例；物件後綴 `_LOD0/_LOD1/_LOD2` 可讓 Unity 自動建立 LODGroup。Sockets 以空物件匯出。
- URP：`MetallicSmoothness`（R = 金屬度，A = 平滑度）直接接 Metallic Map；Normal 為 OpenGL 切線空間。
- 發光件（丹爐火 `Fire` 群組、燈紙）的 Emission 貼圖是點亮時的顏色；冷爐／熄燈狀態請在遊戲中把 emission 強度設 0 或隱藏 `Fire` 物件。
- 十視圖使用 SectFacilities05 相同燈光、曝光 -1.3，與既有圖庫一致；引擎內亮度需另外調。
