# 《雲境》產品、玩法與協作分工 v0.4

狀態：審閱草案  
日期：2026-10-25  
目的：先決定遊戲平台、完整玩法骨架及核心團隊與兩位協作者的工作邊界，再擴建正式場景與內容。

本文件是下一階段的提案，不代表所有功能已實作。現況仍以 [status.md](status.md) 為準。

## 一、產品形態

### 決策建議

《雲境》採用：

> **手機橫向 App 為主要版本，Windows 為同帳號、同角色、同世界的高畫質版本。**

不把完整遊戲製作成瀏覽器 Web 遊戲。網頁只負責：

- 官網、公告、活動日曆與版本資訊。
- 帳號綁定、裝置管理及客服入口。
- 角色和洞府的只讀展示；未來可做不影響戰力的輕量操作。
- 營運後台，不提供一般玩家存取。

### 為什麼以 App 為主

| 面向 | 手機 App＋Windows | 完整 Web 遊戲 |
|---|---|---|
| 3D 畫面與效能 | 可直接控制畫質、記憶體、Shader、資源分包 | 瀏覽器記憶體、載入、相容性限制更多 |
| 操作 | 手機觸控、手把、鍵鼠分別調校 | 瀏覽器輸入、全螢幕與焦點管理更複雜 |
| 大型素材 | 可按州域下載、背景更新 | 首次載入和快取管理較難穩定 |
| 跨平台 | Unity 共用主要規則與素材 | 仍要另外處理 WebGL 限制與伺服器相容性 |
| 長期營運 | 推播、更新、裝置驗證較完整 | 適合展示與輕量玩法，不適合本作主體 |

### 裝置定位

- 手機是最大多數玩家的主要入口，30 FPS 是基準，60 FPS 是高階選項。
- Windows 提高解析度、陰影、視距、植被與特效，不改變碰撞、掉落或戰鬥規則。
- 同一角色同時只允許一個可操作連線；換裝置時交接控制權。
- 手機可完成全部核心內容，不把精準戰鬥或高階副本限定在 PC。

## 二、遊戲一句話與核心承諾

> 玩家帶著真正不同的先天資質進入共同修仙世界，先以普通人的方式謀生與修行，十日後接受測資並加入宗門，再透過戰鬥、經營、研究、師承、秘境與合作走出自己的道路。

四項核心承諾：

1. **出生真的不同。** 天才有實際優勢，凡骨也有內容完整但更艱難的路。
2. **修行不是單純刷經驗。** 境界需要功法掌握、身體條件、材料準備及實際試煉。
3. **生活系統支撐修仙。** 種植、煉丹、煉器、陣法、符籙與御獸都能改變探索和戰鬥。
4. **世界有人共同生活。** 玩家會相遇、合作和留下建設成果，但不讓大公會壟斷個人進度。

## 三、完整玩家旅程

### 階段 0：創角與隱藏先天

玩家自訂外觀後建立唯一修行身分。伺服器在同一交易內完成：

- 隨機分配先天靈根、體質、靈竅及初始身體狀態。
- 保存不可重抽的出生紀錄。
- 配發基礎衣物、工具、少量靈石與《煉氣訣》。
- 設定創角時間；滿十個現實日才開放正式測資，離線也計時。

十日前只告訴玩家可以做什麼，不揭露精確品質和稀有度。玩家能從實際修煉感覺到差異，但不能用介面反覆探測後換帳號。

### 階段 1：創角後前十日，自由摸索期

前十日不再切成第 1–3、4–6、7–9 日的強制教學階段。所有人從「青溪山院」共同聚落開始，取得暫住床位、基礎箱子、修煉位置和《煉氣訣》，世界立即開放以下可能性：

- 在住處引氣、打坐、研究《煉氣訣》或鍛鍊身體。
- 採集草藥、木材、礦石，觀察材料用途。
- 狩獵山兔等低級獵物，出售、委託加工或保留材料。
- 接受居民委託、協助水渠、探索青溪異常及失落遺跡。
- 旁觀或嘗試靈植、煉丹、煉器、陣法、符篆與御獸的入門操作。
- 與其他玩家組隊、交易、交換情報，或完全獨自遊玩。
- 從行腳修士、舊碑、傳聞、遠方山門和特殊事件自行發現宗門線索。

系統提供「你可以做什麼」的環境提示，不提供「今天必須完成什麼」的日程表。教學採情境觸發：玩家第一次碰到藥草才介紹辨識，第一次拿到獵物才介紹處理，第一次主動閱讀功法才介紹運轉。提示可以跳過，也能在見聞錄重新查看。

新手引導只保證三件事：知道如何行動、知道失敗後如何恢復、知道世界裡有多條路。它不替玩家選路，也不要求在指定日完成宗門課程。玩家可能第一天便專心狩獵，也可能十日都在研究草藥；兩者都能累積有效成果。

十日計時只決定正式測資何時開放，不限制每天內容、不要求連續登入。若玩家很早探索到宗門人物，只會得到傳聞、短暫指點或觀察機會，不提前揭露完整資質與正式錄取結果。

#### 前十日的可玩閉環

前期不是十天倒數畫面，而是五條從第一天便能走深的路：

| 路線 | 玩家實際做什麼 | 立即成果 | 十日前可累積的長期成果 |
|---|---|---|---|
| 修煉 | 閱讀《煉氣訣》、嘗試感氣、安排周天、處理氣息不穩 | 靈氣、氣血和身體狀態變化 | 煉氣訣掌握、經脈認知、體修基礎 |
| 採集 | 看外形與環境辨識材料、採收、清理、保存 | 草藥、礦石、木材 | 地區圖鑑、採集手法、材料知識 |
| 狩獵 | 找足跡、判斷風向、接近、戰鬥、處理獵物 | 肉、皮、骨和妖獸材料 | 武技熟練、獵物知識、路線情報 |
| 謀生 | 自售、交委託、委託加工、比較坊市需求 | 靈石、工具、丹藥和裝備 | 商譽、固定客戶、加工關係 |
| 探索 | 跟傳聞、讀舊碑、進洞穴、調查青溪異常 | 寶箱、線索、特殊材料 | 地圖標記、宗門情報、世界事件進展 |

每條路都採「看見線索 → 自己決定準備 → 行動 → 取得結果 → 發現新選擇」的循環。玩家不必先解完採集教學才能狩獵，也不必完成青溪事件才能修煉。

暫住處提供不會遺失的基礎箱子及打坐位置；坊市提供最低限度的基礎工具和回收服務。凡骨玩家若無法正常引氣，第一次嘗試就會得到可理解的身體反應與鍛體線索，立即能改走站樁、負重、藥浴準備和武技，不會被卡在「等第十日才有玩法」。

第十個現實日到達後，測資大典永久解鎖，不要求玩家在某個固定時刻上線。尚未準備好的玩家可以繼續原本生活，之後再自行前往廣場。

### 階段 4：第 10 日，廣場測資與宗門選比

完整流程：

1. 在測資廣場啟動中央測靈晶石。
2. 揭露出生紀錄，說明靈根、體質、靈竅、經脈及目前修行狀態。
3. 各宗門依自己的傳承評估適性，不給全服唯一戰力分數。
4. 玩家完成與方向相符的基礎試煉。
5. 顯示各宗門願意給予的起始身分：雜役、外門或內門。
6. 玩家自己選擇去哪個宗門；高資質不強制選擇最高待遇。

宗門沒有招生名額，不由玩家會長審核。低資質者可從雜役或外門晉升，不被永久封鎖傳承。

### 階段 5：入宗與正式洞府

首次入宗一次性取得：

- 私人洞府空間。
- 床、箱子、修煉蒲團與基礎工作台。
- 一塊可種植靈田。
- 宗門服飾和起始功法資格。
- 第一批個人任務及貢獻取得方式。

宗門大殿、課堂、坊市、演武場等公共區多人可見；私人洞府預設個人實例，未來可邀請訪客。玩家能看到宗門總弟子、近期活躍與目前在線，不把總帳號數偽裝成現場人數。

### 階段 6：長期修行

長期遊玩由六條互相連接的線組成：

- 境界：煉氣／淬體 → 築基／體修築基 → 結丹／體丹。
- 師承：導師、功法、掌握、轉修與個人傳承。
- 洞府：靈田、水路、丹房、器坊、陣眼、棲地和布置。
- 技藝：材料研究、可靠配方、委託生產和專精。
- 世界：青溪、斷脈遺跡、宗門區域、野外危機和共同工程。
- 秘境：限時探索、路線取捨、資源風險和撤離。

## 四、自發遊玩的核心設計

本作不以「每幾分鐘該做什麼」規定玩家的在線時長。一次登入可以只查看田地，也可以連續探索數小時；同一項活動不因遊玩時間短便被分類成次等內容。

玩家願意回來的理由建立在五種吸引力：

1. **自主**：同一個成長目標可透過修煉、採獵、生產、交易、師承或合作處理。
2. **精通**：操作、配方、功法和技藝具有能被理解及練熟的深度，努力會留下可見能力。
3. **好奇**：地圖、傳聞、秘境、師承與材料組合提供尚未解開的問題。
4. **表達**：主修、跨修、洞府、裝備和解決事件的方法能表現玩家選擇。
5. **連結**：玩家能互相幫助、展示成果和留下共同紀錄，但不靠公會權力扣住進度。

這個方向參考自我決定理論所強調的自主、能力感與連結感，以及玩家動機研究中常見的精通、成就、沉浸、創造與社群差異。設計上會用試玩資料驗證，不把理論名稱當成好玩的證明：

- [Self-Determination Theory in Digital Games](https://selfdeterminationtheory.org/wp-content/uploads/2017/01/2016_Uysal_Yildirim_Gamer_Psych_Beh.pdf)
- [Quantic Foundry Gamer Motivation Model](https://quanticfoundry.com/gamer-motivation-model/)

### 目標網，而不是待辦清單

玩家同時能看見多個自己選擇的目標，例如改善引氣效率、買一把法劍、找出水源異常、練熟一張符或存材料建工作台。每個目標顯示可能線索，不顯示唯一正解。

任務分成三類：

- **世界線索**：告訴玩家哪裡有異常、人物或傳聞，不要求接受。
- **個人志向**：由玩家自己標記長期目標，系統記錄進展。
- **正式委託**：有明確報酬和期限，但不構成每日必做清單。

不採連續登入懲罰、每日清單全清獎勵或離線損失。作物成熟後保留，閉關和基礎研習可依已安排內容離線推進。營運活動負責創造值得談論的新機會，而不是用紅點逼玩家停留。正式宣傳則使用公開樣片、開發紀錄、試玩版、社群事件與商店願望清單檢驗市場興趣；Steam 官方也建議以持續更新、事件和實際流量資料觀察玩家反應，而不只追逐表面曝光量：[Steamworks Visibility](https://partner.steamgames.com/doc/marketing/visibility)、[Steamworks Wishlists](https://partner.steamgames.com/doc/marketing/wishlist)。

## 五、先天與後天成長

### 出生層級測試表

| 類型 | 機率 | 實際影響 |
|---|---:|---|
| 凡骨 | 10% | 無先天靈根，先走體修、藥浴、武技或後天開靈 |
| 常資 | 76.97% | 能正常修行，選擇與資源配置最重要 |
| 良才 | 10% | 較佳吸收、靈竅或適性組合 |
| 天驕 | 3% | 明顯更快、更早承載高要求功法 |
| 天命 | 0.03% | 極稀有頂級組合和專屬體質 |

出生不是一個總戰力數字，而是六組資料：靈根、體質、靈竅、經脈、丹田／氣海、先天特性。

### 後天改變

- 凡骨可以一路體修，也可完成長期事件取得後天靈根。
- 靈竅可以開啟，經脈可以修復和強化。
- 體質可調理與淬鍊，但不能廉價複製別人的先天專屬體質。
- 天才保留實際速度和容量優勢，不用隱藏懲罰硬把所有人變成一樣強。
- 核心進度不放在極低機率世界王掉落或玩家公會分配中。

## 六、修行與突破

突破由三部分構成：

1. 準備：修為、材料、身體及裝備狀態。
2. 掌握：功法熟練、經脈配置、淬體或技藝成果。
3. 試煉：路線對應的操作與判斷。

失敗要告訴玩家原因並給修復路徑，不用「材料全扣後隨機失敗」。失敗不重抽天賦、不清空境界、不永久破壞帳號。

| 路線 | 突破偏重 |
|---|---|
| 劍修 | 劍勢控制、破綻判斷、本命劍共鳴 |
| 體修 | 氣血循環、承壓、藥浴和身體控制 |
| 法修 | 元素順序、經脈運轉、環境導能 |
| 生產專精 | 材料理解、穩定工序、以技藝解決試煉條件 |

首個正式版本做到結丹等價境界。元嬰、化神保留世界設定，不先空做大量上層內容。

### 宗門不是職業鎖，而是傳承環境

世界設定先建立十四個可持續擴寫的宗門。宗門各有主傳承、次傳承、長老分支和不擅長領域，不採「一個宗門只對應一種職業」。

| 宗門暫名 | 主要傳承 | 可延伸方向 |
|---|---|---|
| 太玄道院 | 綜合法修、經脈與基礎正法 | 多位長老、轉修、兼修 |
| 問劍山 | 劍修、本命劍、御劍 | 劍陣、金行、風行 |
| 玄岳宗 | 體修、氣血、護體 | 藥浴、土行、近戰兵器 |
| 丹霞谷 | 煉丹、靈植、調理 | 火候、毒理、醫修 |
| 天工門 | 煉器、機關、法寶 | 礦材、傀儡、器陣 |
| 萬符宗 | 符篆、封印、一次性術式 | 雷符、護符、追蹤 |
| 天衍陣宮 | 陣法、地勢、靈脈推演 | 洞府、生產、戰陣 |
| 五行宮 | 金木水火土法修 | 冰、風、雷等變化支系 |
| 御靈谷 | 御獸、共生、棲地 | 偵察、戰鬥、洞府工作 |
| 合歡宗 | 陰陽調和、情志、共鳴與雙人術式 | 輔助、幻術、神識；不以露骨內容作核心 |
| 玄冥宗 | 魔道功法、濁息與力量控制 | 高風險術式、調理、封禁 |
| 梵心寺 | 神識、心境、護持與肉身禪修 | 淨化、反制、救援 |
| 百草門 | 藥田、醫修、環境療癒 | 水木法術、毒與解毒 |
| 天音閣 | 音律、神識干涉、群體術式 | 控場、增益、情報 |

這十四宗是世界與內容藍圖，不代表第一版同時完成十四套大型山門。第一個可玩版本只完整實作少數宗門的入門流程，其餘先用人物、傳聞、使者、功法殘頁和遠景建立存在感，再逐批完成。

玩家的靈根和體質影響適性，不替玩家決定宗門。冰靈根可以加入玄岳宗鍛體，凡骨也可以研究符篆；差別表現在理解速度、經脈負擔、導師建議和需要的替代方法。每個宗門至少提供一條主流路線與一條跨適性路線，讓「明知不合仍想修」成為有內容的選擇，而不是按鈕被鎖住。

## 七、戰鬥

### 手機操作基準

- 移動、鏡頭、普通攻擊。
- 一個閃避／防禦操作。
- 兩個功法技能。
- 一個本命技能。
- 一個快捷消耗品。

提供目標鎖定、輔助瞄準、鏡頭減震、按鍵調整。PC 和手把仍使用相同技能容量，避免 PC 因多十個快捷鍵取得規則優勢。

### 戰鬥差異

- 劍修：距離、劍勢、破綻、御劍和劍陣。
- 體修：格擋、反擊、壓制、救援和承受環境傷害。
- 法修：元素狀態、施法順序、範圍控制和環境改變。
- 魔道功法：與主修組合，以濁息換短期力量，需要控制與調理，不等同惡意 PK。

敵人以動作、聲音和地面提示表達威脅。合作貢獻包含傷害、控場、護陣、救援和環境操作，不採最後一擊獨占。

首版只有雙方同意的切磋，不做強制野外 PK。大型 PvP 是否加入，待核心 PvE 與經濟穩定後再決定。

## 八、技藝、洞府與經濟

### 技藝全部可學，但精通需要長期投入

| 技藝 | 主要決定 | 支援玩法 |
|---|---|---|
| 靈植 | 品種、土壤、水源、鄰植、採收 | 丹藥、藥浴、環境修復 |
| 煉丹 | 藥性、配比、火候、用途 | 修行、治療、調理 |
| 煉器 | 材料、結構、器紋 | 武器、工具、洞府設備 |
| 陣法 | 節點、連接、供能、範圍 | 生產、戰鬥、解謎 |
| 符籙 | 效果、觸發條件、容量 | 一次性戰術和探索工具 |
| 御獸 | 習性、接近、培養、指令 | 偵察、戰鬥、洞府工作 |

材料共用屬性、材性／藥性、純度、穩定性，避免六個系統各有互不相干的稀有度。

玩家不需要在創角時永久選死一項技藝。六種都能入門，但同時深入修習會受到時間、材料、導師、工作設施與「悟法心力」限制：

- 每個角色同時可指定一項主修技藝，獲得完整的主動練習與離線參悟效率。
- 另可安排兩項輔修，但參悟效率較低；其餘技藝仍能操作基礎功能和累積少量經驗。
- 改換主修不清除既有成果，需經一段重新熟悉期，防止每次製作前瞬間切換專精。
- 常資玩家把一項技藝從入門練至能穩定獨立製作，初始目標約需 20–30 個現實日；高階專精以數月計。
- 這 20–30 日不是單純倒數。研究材料、實際製作、處理失敗、完成導師課題和在事件中使用技藝，會形成不同的掌握成果；離線參悟只推進已理解的部分。
- 玩家不必每天登入。缺席不會倒扣進度；專注玩家的優勢來自長期選擇和有效實踐。

先天條件會影響速度和上限，但不作硬性封鎖。例如火靈根、陽性經脈或控火體質可能提高煉丹火候掌握；金靈根可能較容易理解器紋；神識特性可能幫助陣法與符篆。天生不適合仍可學習，只是需要更好的導師、替代工序、設備或更多練習。

功法也使用相同原則：角色可以接觸劍、體、法、魔道及其他傳承，但功法熟練、經脈承載、實戰理解與師承資源讓「全部會一點」和「專精一門」形成真實差距。專精者能更早取得高階變化；廣修者擁有更多解法，但不會迅速把每一門都練滿。

### 洞府資源

水量、靈氣、土壤、陣法承載與工作位互相競爭。擴建是新的配置選擇，不只增加數字。訪客能使用主人允許的設備；採收、搬走物品和拆建築需要明確權限。

### 經濟

- 靈石是主要交易媒介；靈礦不直接無成本變成貨幣。
- 普通材料與成品可交易；突破領悟、個人試煉及宗門貢獻綁定。
- 固定價格刊登與託管代煉先上線，不先做全服競標拍賣。
- NPC 提供基本服務，沒有玩家接單時也不封鎖核心進度。
- 修理不降低裝備永久上限。
- 首版不開玩家直接送大量靈石和自由丟物，降低刷號洗資產。

## 九、秘境

秘境在玩家正式加入宗門後才開放。它不是平常每日活動，而是由本週世界局勢與營運配置決定的宗門大事件。

### 每週產生與發布流程

1. 系統每週從已通過測試的秘境模板中產生 1–3 個候選秘境。
2. 每個候選包含地圖、事件種子、准入宗門、境界／角色世界年齡門檻、獎勵表與風險規則。
3. 准入宗門可以互相重複，也可以出現全宗門秘境；沒有取得本週資格的宗門不能入場。
4. 營運管理員在後台覆核候選，可改選模板、宗門、門檻、開放時間和公告內容；未經發布的隨機結果不會直接出現在正式環境。
5. 建議每週五晚間公布，讓宗門成員準備；每週六 20:00 開放主要入口。確切時區、入場窗口和補開政策要在封測觀察後固定。
6. 玩家在入口開放時進場，每次探索上限約一小時；進場後各隊獨立計時。

營運後台至少要能設定：秘境模板與版本、准入宗門複選、最低／最高境界、角色世界年齡、開門時間、入場截止時間、每人次數、事件種子和獎勵版本。新秘境地圖必須先隨遊戲內容更新完成測試；後台只能啟用已上傳且相容的版本，不能在正式環境任意上傳未知執行檔或未驗證資產。發布後保留完整操作紀錄，只有緊急取消，不能暗中改掉已公告的門檻與獎勵。

固定時段會製造共同期待，也確實會排除當時無法上線的人。為保留這項世界稀有感，首版接受秘境機會並非人人每週相同，但不把唯一突破資格、不可替代功法或付費資源只放在單一週六時段。營運資料要分別觀察各時區參與率，之後再決定是否增加同週第二場入口。

秘境核心仍是「在有限時間內判斷風險、尋找機緣並安全帶出成果」，不是只有一條路打王。

每個秘境包含：

- 入口條件：本週准入宗門、境界、角色世界年齡、場次、個人次數。
- 探索時計：約一小時；提前撤離可保存已結算成果。
- 多條路線：穩定材料、危險機緣、解謎捷徑、合作工程。
- 資源負重：帶得越多，撤離風險和選擇越重要。
- 死亡規則：不掉入場前財產；秘境內未封存收益部分損失，具體比例待定。
- 單人和 1–4 人都能完成基本目標；多人提供不同解法。

第一批只製作兩個經完整測試的模板：

1. 通用「青溪藥谷」：採藥、生態、濁氣和低級妖獸。
2. 宗門「斷脈古府」：修陣、偵察、戰鬥及撤離。

驗證玩法成立後，再增加模板和事件模組。隨機指的是從安全組合中產生本週局勢，不在上線當下即興生成未測試的地形、怪物與獎勵。

## 十、多人世界與防壟斷

| 空間 | 規模 | 作用 |
|---|---:|---|
| 私人洞府 | 主人；訪客後續開放 | 生產、布置、閉關 |
| 山院 | 24 名固定居民；每分線 12 人 | 鄰居、公共工程、日常相遇 |
| 宗門、坊市、野外 | 每分線 12 人 | 教學、交易、探索、活動 |
| 小隊秘境 | 1–4 人 | 完整遭遇與分工 |
| 公共危機 | 每場 12 人 | 妖獸、靈脈與環境危機 |

- 宗門由開發者建立，玩家不能創建控制核心資源的宗門。
- 山院沒有玩家會長，不由玩家扣住獎勵。
- 世界王按個人資格發獎，不看最後一擊或傷害排名。
- 核心突破材料有個人穩定路徑。
- 好友優先同線；滿員時整隊進另一條分線。
- 不活躍山院可搬遷，個人洞府和資產跟隨角色。

## 十一、樹伴連動

連動可選，不是遊戲必需品：

- 樹伴種植長週期靈草，可輸送到自己綁定的《雲境》角色。
- 接收有連續 28 日上限，原料和衍生成品維持綁定。
- 提供省時與穩定性，不直接增加永久靈根、不替代突破試煉。
- 不使用樹伴仍能在遊戲內取得同級用途材料。
- 遊戲和樹伴後端、資料庫、憑證保持獨立。

這項功能要等資產帳本、重送、防複製及取消流程驗證後才開放。

## 十二、美術與大世界方向

已選方向：

- A「暖陽河谷」的清楚地圖骨架。
- D「古木青溪」的生活、靈植與濕地氣質。
- B「雲瀑山門」作為遠方宗門及後續山門區。
- C「斷脈靈湖」作為稀有世界奇觀和中後期主線區。

初期大世界採分區而非真正全服無縫地圖：

1. 青溪山院與測資廣場。
2. 聚落坊市及暫住區。
3. 靈草濕地與教學藥圃。
4. 竹林採集區。
5. 低級狩獵丘陵。
6. 青溪斷流上游。
7. 宗門渡口／山門遠景入口。

每區先定玩法、尺度、玩家密度與效能預算，再做地形和資產。自行製作任何物件，仍須先生成、檢視及保存 AI 三視圖後再建模。

## 十三、首個可玩版本範圍

### 必須完成

- 一個共同聚落和五個相連小區域。
- 創角、隱藏出生、十日計時、測資廣場。
- 凡骨和普通修士兩條可走通路線；稀有資質用測試身分驗證。
- 體修與法修的基礎戰鬥；一種低級敵人。
- 採集、交易、靈植、煉丹和簡單符篆／陣法。
- 十四宗世界名單；太玄、玄岳、萬符三個可正式選擇的首批入門流程。
- 入宗配發洞府、床、箱子與一格靈田。
- 青溪斷流的一條完整體驗鏈，不規定玩家必須在一次登入內完成。
- 1–4 人合作，重登後成果仍在。

### 先不做

- 十四宗門全部完整場景。
- 元嬰、化神及上界。
- 強制 PvP、大型宗門戰和玩家創宗。
- 全服無縫大地圖。
- 大規模寵物繁殖和遺傳系統。
- 完整自由建築、玩家土地圈占。
- 真人唯一性的虛假保證。

## 十四、核心製作單位與兩位協作者

**使用者與 Codex 視為同一個核心製作單位。** 使用者提出目標、判斷體驗並作最終決策；Codex 依指示完成研究、規格、程式、測試、文件、工具與可執行工作。兩者不拆成兩個互相交件的職位，也不分別計算人力。

### 核心製作單位：使用者＋Codex

- 決定產品方向、世界觀、玩法規則、視覺基準與優先順序。
- 負責最難、最核心、會決定遊戲品質的工作，包括世界骨架、主要系統、關鍵場景與整合。
- 完成出生、修煉、宗門、技藝、秘境、經濟、伺服器、Unity 互動和測試。
- 需要建模時，先依規則產生並檢視 AI 三視圖，再由核心單位或協作者建模。
- 審核所有協作者成果，決定是否合併、修改或重做。
- 對外只提供清楚工作包和驗收條件，不把尚未確定的設計丟給協作者自行猜測。

### 協作者 A：3D 資產製作，暫定

這個角色適合專注模型、貼圖與動畫量產：

- 人物、NPC、妖獸、武器、道具、建築模組、家具和植被。
- 模型清理、UV、材質、骨架、動畫、LOD、碰撞代理及匯出。
- 每件素材附三視圖、比例、面數、動作、來源及已知缺項。
- 依核心單位提供的互動需求製作，不自行決定掉落、數值或玩法規則。

### 協作者 B：場景落地與技術美術，暫定

第二位協作者目前不急著綁定姓名；本版建議讓他負責最容易成為瓶頸的「模型進遊戲後」工作：

- 依灰盒配置場景模組、地形、道路、植被、碰撞與導航區域。
- Unity 材質、燈光、LOD、遮擋、資源分包和手機畫質級別。
- 將協作者 A 的素材組成可重用 prefab，回報比例、法線、骨架和效能問題。
- 維護場景檢查表並執行實機效能、穿模、導航與畫面一致性測試。
- 不改動伺服器資產判定和核心玩法程式。

若第二位協作者的專長並非 Unity／技術美術，這個職位可以改成內容與 QA：製作宗門人物、委託、秘境事件資料，並依測試表反覆遊玩回報。確認兩位協作者能力前，不把永久責任寫死。

### 功能流動範例

以「山兔狩獵」為例：核心單位完成玩法、AI、掉落規則、三視圖和驗收標準；協作者 A 製作模型與動畫；協作者 B 將狩獵區、植被、碰撞、導航和畫質落地；核心單位接入伺服器並驗收完整體驗。

## 十七、進入量產前必過門檻

- 手機和 Windows 能登入同一角色；此項目前尚未實測完成。
- Unity 專案能在固定版本編譯，授權問題已解決。
- 一名玩家可以完成第一小時；四人能完成青溪樣片。
- 伺服器判定資產、掉落與採收，重送不重複發獎。
- 山兔具有完整最低動畫和伺服器 AI，不是靜態模型。
- 測資廣場能正確保護十日前的隱藏資料。
- 30 分鐘手機實機測試記錄幀時、溫度和記憶體。
- Git LFS 的模型、貼圖和 Blender 原檔能從乾淨 checkout 下載。

門檻未通過前，不量產十四宗門、五張秘境或大量商城外觀。

## 十八、v0.4 已修正與待審定方針

本版建議先採以下預設；你可逐項修改：

1. 平台：手機 App 主版＋Windows 同步版；不做完整 Web 遊戲。
2. 大世界：A 河谷結構＋D 古林氣質；B 宗門、C 斷脈後續區。
3. 自發遊玩：取消分鐘式玩法表和每日必做，以目標網、精通、探索、表達及合作形成動機。
4. 前十日：所有主要基礎活動立即可探索；宗門靠世界線索自行發現，不安排第 7–9 日強制介紹。
5. 技藝：全部可學；主修一項、輔修兩項，常資穩定掌握一項初始目標約 20–30 日，靠實踐與參悟累積。
6. 秘境：入宗後才開；系統每週產生 1–3 個候選，營運覆核後週五公告、週六 20:00 開放。
7. 秘境死亡：不掉入場前資產，損失部分尚未封存的秘境收益。
8. 年齡：使用角色世界年齡，不直接使用真人生日；具體時鐘另定。
9. 宗門：官方建立十四宗世界藍圖；首批完整太玄、玄岳、萬符，玩家不創立控制核心資源的宗門。
10. 跨修：靈根與體質影響效率和負擔，不硬鎖宗門及修行方向。
11. 首版境界：做到結丹等價，不先做元嬰／化神。
12. 分工：使用者＋Codex 是同一核心製作單位；兩位外部協作者暫分 3D 資產，以及場景落地／技術美術，待確認專長後定名。

上述方針審定後，才把工作包轉成 GitHub Issues、里程碑和實際排程。
