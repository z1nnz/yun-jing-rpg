# 雲境｜介面與操作設計方向 v1（草案）

> **狀態：v1 採用。** 2026-10-29，Claude Code 撰寫。z1nnz 授權 Claude Code 決定，並指示「風格可以不用固定，但要像同一個世界」。決定見第 11 節。
>
> 範圍：網頁外殼（載入、安裝、橫屏提示）、遊戲內 HUD、手機搖桿與按鍵、電腦鍵鼠操作、圖示系統、選單。角色與世界的美術規格見[建模風格規格](modeling-style-spec-v1.md)。

## 0. 現況（要被換掉的東西）

| 部分 | 現在 | 問題 |
|---|---|---|
| 網頁外殼 | Unity 內建 PWA 範本 | 白底、Unity 標誌和藍色進度條，一看就是範本 |
| HUD 與選單 | `OnGUI`（IMGUI）灰色方框與純文字 | 沒有美術、無法做動畫、手機上字小又擠 |
| 搖桿 | 位置固定、看不見的圓 | 沒有底盤、沒有回饋，拇指不知道自己在哪 |
| 按鍵 | 110×70 灰色方塊，文字「跳」「跑」「互動 F」 | 不是圖示，也不按使用頻率排；戰鬥時 9 個方塊排成一面牆 |
| 圖示 | 沒有 | — |

結論：這不是調色就能救的，要整套重做。現有的觸控**邏輯**（多點觸控、虛擬輸入 `VirtualMove` 等）可以保留，換掉的是畫面與排版。

## 1. 目標：比原神好在哪裡

原神介面的優點要學：資訊少、手機單手好按、主要按鍵大、技能冷卻一眼看懂、探索時畫面乾淨。
它的弱點就是我們要超越的地方：

| 原神 | 雲境要做到 |
|---|---|
| 介面是「貼在畫面上的通用奇幻金框」，與璃月、蒙德的世界無關 | 介面本身就是**修仙世界裡的器物**：玉、紙、墨、銅、印。看到介面就知道是雲境 |
| 圖示多為白色扁平剪影，換到任何遊戲都成立 | 圖示有**筆意與材質**：墨線、篆印、玉片切面，但縮到 32 px 仍清楚 |
| 右上角常駐 6–8 個圖示，畫面角落很擠 | 探索時只留必要的；其他收進「乾坤袋」一個入口 |
| 轉場多是白閃、淡黑 | 用**墨暈、雲霧、紙捲**轉場，0.3–0.6 秒，不拖慢操作 |
| 提示是浮動文字條 | 重要事件用**印章蓋下**（機緣、境界、獲得法寶），一般提示用細字 |

但不能為了「有風格」犧牲可讀性：每個元素先要好按、好讀，再談好看。這條比任何裝飾優先。

## 2. 視覺語言：「玉、紙、墨、銅」

| 材料 | 用在哪裡 | 做法 |
|---|---|---|
| 玉（青白玉，半透明） | 搖桿底盤、主要按鍵、技能環 | 帶內部光暈的圓片，邊緣有切面高光；按下時亮度提高、略縮 |
| 紙（宣紙、絹） | 對話框、任務、選單底 | 米白紙紋＋淡墨邊，邊角不規則；暗色版用深色絹 |
| 墨 | 文字、圖示線條、轉場 | 主要文字用深墨；圖示用帶粗細變化的筆觸 |
| 銅（氧化銅、舊金） | 邊框、分隔線、重要按鍵的包邊 | 只在少量邊緣使用，不做大面積金框 |
| 印（朱砂印） | 重要通知、新物品、未讀標記 | 小方印或圓印，紅色只在這裡出現 |

### 2.1 色票（與建模規格同一套，另加介面專用）

| 代號 | 色 | 用途 |
|---|---|---|
| `ink-900` | `#1C1F1E` | 主要文字（亮底）、深色面板底 |
| `ink-600` | `#4A5250` | 次要文字 |
| `paper-100` | `#F2ECDF` | 亮色面板底 |
| `paper-300` | `#D9CFBD` | 面板邊、分隔 |
| `jade-300` | `#9FD8CC` | 玉片高光、可按狀態 |
| `jade-500` | `#5FA89A` | 玉片主色 |
| `jade-glow` | `#7FE0D4` | 選中、靈氣、冷卻完成 |
| `bronze-500` | `#A8874E` | 少量包邊、分隔線 |
| `gold-300` | `#E8C877` | 稀有、機緣 |
| `cinnabar-600` | `#B23A2E` | 印章、未讀、危險（僅這三種用途） |
| `mist-white` | `#EEF2F2` | HUD 上的文字（疊在 3D 畫面上，搭配陰影） |

規則：
- HUD 疊在遊戲畫面上，文字一律 `mist-white` 加 2 px 深色柔陰影，不用描邊。
- 紅色只用於印章、未讀與危險。不把紅色當裝飾。
- 一個畫面最多一個 `jade-glow` 焦點，不讓所有東西同時發光。

### 2.2 字體

| 用途 | 字體 | 大小（手機，1080 p 高的參考畫面） |
|---|---|---|
| 標題、地名、境界名 | Noto Serif TC Bold（已內建）；地名之後可換書法體，需確認授權 | 48–64 px |
| 選單標題 | Noto Serif TC SemiBold | 32–36 px |
| 內文、對話 | Noto Sans TC Regular | 26–28 px，行高 1.5 |
| 按鍵小字、數字 | Noto Sans TC Medium | 22 px 以上，**不得更小** |

數字（傷害、數量、冷卻）用等寬數字。不用細體字疊在 3D 畫面上。

## 3. 手機操作

### 3.1 搖桿（左下）

- **浮動搖桿**：左半邊下方 60% 的區域任何地方按下，底盤就出現在拇指下；放開後淡出，並回到預設位置（左下，距左 160 px、距底 160 px，以 1080 p 計）顯示 40% 透明度的提示。
- 底盤：青白玉圓片，直徑 220 px；中央把手直徑 96 px，有篆紋。
- 死區 12%；推到 85% 以上進入「奔跑」（不需另外按「跑」），把手外圈亮起 `jade-glow`。
- 推到邊緣後繼續往外拖，底盤會跟著拇指移動，不會「卡在邊」。
- 回饋：開始奔跑時輕微震動（`navigator.vibrate` 或原生觸覺，可在設定關閉）。

### 3.2 視角（右半邊空白處拖曳）

- 靈敏度預設與電腦滑鼠分開調，設定可調 0.3–3.0 倍；可選反轉 Y。
- 兩指捏合：縮放第三人稱鏡頭距離（之後有第三人稱時）。

### 3.3 按鍵（右下，弧形排列）

按使用頻率由拇指自然位置向外排列，像原神但數量更少：

| 位置 | 探索時 | 戰鬥時 |
|---|---|---|
| 主鍵（最大，直徑 150 px，最靠右下） | 互動／採集（只在有可互動物時顯示圖示；否則顯示「跳」） | 攻擊 |
| 弧上第 1 顆（110 px） | 跳 | 閃避 |
| 弧上第 2 顆（110 px） | 御氣（之後的輕功／衝刺） | 法術（帶冷卻環） |
| 弧上第 3 顆（110 px） | — | 格擋（按住） |
| 右上角小鍵（80 px） | — | 回安全點 |

- 互動不再是固定按鍵：靠近可互動物時，**物件名稱與圖示出現在主鍵旁**（例如「採集　青心草」），按主鍵即可。這是取代原神「F 列表」的做法，手機更好按。
- 冷卻：玉片內的墨色由下往上退去，退完時邊緣閃一次 `jade-glow`。
- 按下回饋：縮到 92%、亮度 +15%、80 ms；放開回彈 120 ms。
- 所有按鍵最小可按區域 88×88 px（以 1080 p 計），按鍵之間最少 16 px。
- 左右手可在設定中對調；按鍵位置可在設定中拖曳自訂並儲存。

### 3.4 安全區與方向

- 只支援橫屏。直拿手機時顯示「請橫置手機」的全畫面提示（紙捲插畫，不是系統預設文字）。
- 所有 HUD 避開瀏海與手勢條（`Screen.safeArea`），另留 24 px 邊距。

## 4. 電腦（網頁與 Windows）

| 動作 | 鍵 |
|---|---|
| 移動 | WASD；Shift 奔跑（按住）；Ctrl 切換走路 |
| 視角 | 滑鼠（點畫面鎖定游標，Esc 解除）|
| 跳 | 空白鍵 |
| 互動 | F（多個可互動物時，滑鼠滾輪切換） |
| 攻擊／法術／格擋／閃避 | 左鍵／E／右鍵（按住）／Shift 點按 |
| 地圖、乾坤袋、修煉 | M、B、C |
| 選單 | Esc |

- 畫面上的按鍵提示只在**第一次**需要時出現（例如第一次靠近可採集物），之後隱藏，設定裡可重開。
- 未鎖定游標時，畫面中央顯示「點擊畫面開始」的提示（目前很多人卡在這裡）。
- 可在設定中重新綁定按鍵。

## 5. HUD 版面（探索時）

```
┌──────────────────────────────────────────────────────────┐
│ [地名印]  青溪村 · 晨                       [小地圖] [乾坤袋] │
│                                                          │
│                                                          │
│                     （畫面中央：無）                       │
│                                                          │
│ [任務：一行，可收起]                                        │
│                                                          │
│ (搖桿)                              [採集 青心草] (主鍵)   │
│                                         (跳) (御氣)       │
└──────────────────────────────────────────────────────────┘
```

- 探索時常駐只有：地名、小地圖、乾坤袋、任務一行、搖桿與按鍵。
- 生命與靈氣條**只在受傷、施法或戰鬥時出現**，5 秒後淡出。
- 進入新區域：地名以墨字從淡到濃寫出，下方小字顯示區域氣氛（例如「溪聲不絕」），2.5 秒後淡出。
- 發現機緣：畫面中央蓋下一枚朱砂印，配一句短詩；不打斷移動。

## 6. 圖示系統

- **格線**：64×64 px 畫布，內容區 52×52，線寬 3.5 px（在 64 px 時），端點用毛筆收鋒。
- **兩種狀態**：一般（墨色或月白線條）、啟用（線條＋玉色填色）。
- **三種尺寸**：32、48、96 px（以 1080 p 計），每種尺寸手修一次，不只縮放。
- **題材**：用器物表意，不用通用符號。例如：
  - 背包 → 乾坤袋
  - 地圖 → 卷軸
  - 任務 → 竹簡
  - 設定 → 羅盤
  - 修煉 → 蒲團
  - 煉丹 → 丹爐
  - 採集 → 藥鋤
  - 跳 → 雲紋上揚
  - 御氣 → 劍與氣流
  - 攻擊 → 劍
  - 法術 → 符籙
  - 格擋 → 盾形玉璧
  - 閃避 → 殘影
  - 回安全點 → 傳送陣
- **測試**：每個圖示要在 32 px、灰階、色弱模擬下都認得出來，並與同組其他圖示擺在一起比較線寬是否一致。
- 交付：SVG 原稿＋1x、2x PNG；圖示命名 `ico_<名稱>_<狀態>`。

## 7. 網頁外殼（PWA 範本）

自己寫一套 WebGL 範本取代 Unity 內建：

1. **載入畫面**：遠山雲霧的分層插畫，雲緩慢飄動（純 CSS，不等 Unity 載入就能動）。中間是「雲境」書法標題。
2. **進度**：一條墨線由左向右畫出，下方顯示「凝氣中… 43%」與實際下載大小。不顯示 Unity 標誌。
3. **首次進入**：
   - 載入完成後顯示「點擊入境」，同時取得全螢幕與游標鎖定。
   - 手機會提示「加入主畫面」（之後就是全螢幕 App）。
4. **錯誤畫面**：載入失敗或瀏覽器不支援時，用同樣風格說明原因與解決方法，不顯示英文錯誤堆疊。
5. **效能**：外殼本身（HTML＋CSS＋插畫）控制在 300 KB 以內，插畫用 WebP／AVIF。

## 8. 動態與音效

| 事件 | 時長 | 曲線 |
|---|---|---|
| 按鍵按下／放開 | 80／120 ms | ease-out |
| 面板開啟 | 220 ms，紙由中間向兩側展開 | ease-out-cubic |
| 面板關閉 | 160 ms | ease-in |
| 場景轉場 | 400–600 ms，墨暈擴散 | — |
| 印章蓋下 | 180 ms 落下＋60 ms 回彈 | — |

- 每個可按的東西都要有聲音：玉（清脆）、紙（翻動）、印（悶響）。音量可在設定分開調。
- 設定有「減少動態」，打開時轉場改為淡入淡出。

## 9. 技術做法

- **從 IMGUI 換成 uGUI ＋ TextMeshPro**。理由：
  - 可以用九宮格圖片做紙與玉的面板，也可以做動畫與遮罩；
  - 手機上效能可控；
  - 中文用 TMP 動態字型圖集，接現有的 Noto 字體。
- 共用元件做成 Prefab：`UI_JadeButton`、`UI_PaperPanel`、`UI_FloatingJoystick`、`UI_SealToast`、`UI_RegionTitle`。所有畫面只用這些元件組合。
- 版面以 1920×1080 為參考，`CanvasScaler` 用 Match 0.5。HUD 依 `Screen.safeArea` 放置。
- 輸入：沿用 Input System 與現有的虛擬輸入（`VirtualMove`、`VirtualJump` 等）。新的搖桿和按鍵只換畫面與觸控判定，不改玩法程式。
- 圖片集中在一張 2048 圖集（`UI_Atlas_Core`）。手機上 UI 每畫面 draw call ≤ 15。
- 舊的 IMGUI 介面先保留成除錯模式（`?debug`），新介面完成並驗收後再移除。

## 10. 流程與關卡

| 階段 | 產出 | 誰做 | 關卡 |
|---|---|---|---|
| ① 參考板 | 30–40 張參考：器物、書法、玉、紙、優秀遊戲介面（標明學什麼、不學什麼） | Claude Code | Claude Code 決定（z1nnz 已授權） |
| ② 概念圖 | 3 套不同方向的完整 HUD 畫面（手機＋電腦），各含搖桿、按鍵、圖示樣本 | Codex（生圖） | Claude Code 檢查；三套各有用途（第 11.2 節） |
| ③ 線框 | 每個畫面的版面與尺寸標註，依上面第 3–5 節 | Claude Code | 核心組在手機上用灰色方塊試按 |
| ④ 定稿 | 選定方向的高解析設計稿、全部圖示、九宮格素材 | Codex（生圖）＋Claude Code（切圖、SVG） | z1nnz |
| ⑤ 實作 | uGUI 元件、HUD、搖桿、網頁外殼 | Claude Code | 手機實機與網頁實測、截圖對照設計稿 |

驗收標準（第 ⑤ 階段）：
- 在 6.1 吋手機上單手玩 10 分鐘，不按錯鍵。
- 所有文字在手機上不小於 22 px（1080 p 參考）。
- 截圖和定稿並排比較，差異說得出原因。
- 網頁從開啟到可以操作，在一般 4G 網路下有清楚的進度，沒有白畫面。

## 11. 決定（z1nnz 授權 Claude Code 決定）

### 11.1 一套基礎系統，加區域外觀

介面分成兩層：

- **基礎系統（全遊戲不變）**：
  - 搖桿、按鍵的位置、大小、形狀和手感；
  - 圖示的線條規則；
  - 字級、版面、動態時長。
  - 這些不能變，玩家換區域後手指還要記得在哪裡。
  - 材料用「玉、紙、墨、銅」。
- **區域外觀（跟著所在區域換）**：
  - 地名印的樣式、載入插畫、面板紙紋與邊飾、玉的色調；
  - 進入新區域時，在地名出現的同時淡入切換（0.6 秒）。

| 區域 | 紙／面板 | 玉色 | 邊飾 | 地名印 |
|---|---|---|---|---|
| A 青溪河谷 | 米白宣紙 | 青白玉 `jade-500` | 細竹節紋 | 方印、朱砂 |
| D 古林 | 帶纖維的樹皮紙，偏黃褐 | 苔綠玉 `#5E8A5A` | 藤蔓、葉脈 | 不規則石印 |
| B 垂直山城 | 素絹 | 白玉帶金絲 `gold-300` | 雲紋、銅包角 | 圓印、宗門朱 |
| C 裂靈湖 | 深色絹（暗色版） | 月白玉帶淡紫裂光 `#6E5A8C` | 水波、裂紋 | 碎玉印 |

### 11.2 三套概念圖都有用處，不是三選一

| 概念圖 | 用在哪裡 |
|---|---|
| A 玉紙墨銅 | 基礎系統，以及河谷、古林、山城的白天 |
| B 極簡墨線 | 設定裡的「沉浸模式」（把 HUD 減到最少），以及拍照模式、過場 |
| C 暗色絹與舊金 | 夜晚、裂靈湖、秘境、宗門大殿內 |

### 11.3 字體

| 用途 | 字體 | 授權 |
|---|---|---|
| 地名、標題、印章文字 | **霞鶩文楷 TC**（LXGW WenKai TC） | SIL OFL 1.1，免費可商用 |
| 內文、按鍵、數字 | Noto Sans TC | SIL OFL 1.1（已內建） |
| 「雲境」標誌 | 由 Codex 在 C6 手繪成 SVG，不用字型 | 自製 |

付費書法字體暫時不用。之後如果標誌或宣傳圖需要更強的書法感，再另外評估。
