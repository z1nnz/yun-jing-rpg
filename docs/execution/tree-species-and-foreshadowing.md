# 樹種與伏筆 v1

> 2026-10-30，Claude Code。z1nnz：「樹盡量用我那個 elder-tree-esg 等級的那種樹……樹幹也要長不一樣，樹葉也要因為品種不一樣重新設計……一個地方出現不一樣品種的樹是不是不太好，而且也可以在這種地方埋下一點伏筆。」「葉子的精細程度要到我最原始的那個版本的程度才算過關。」
> 資料：`tools/qingxi-terrain/world-dressing.json`（每塊的 `species`、`waterside`、`landmarks`）；模型：`art/exports/elder-trees-v1/`；產生：`tools/art/build_elder_trees_v1.py`（建木）、`tools/art/build_species_trees_v1.py`（其他品種）。

## 一、標準：生命樹原版

量過原版的葉子（`elder-world-tree-hero-v1.glb`），每個品種都照這個標準做：

| | 原版 | 各品種（近看那一層） |
|---|---|---|
| 葉片數 | 61 452 | 約 13 000～30 000（楓葉形狀複雜，片數少一點，面數一樣） |
| 每片大小 | 9～18 cm（中位 13 cm） | 10～20 cm |
| 顏色 | 每片不同：青綠到黃綠，明度 0.51～0.85 | 每片不同；上面受光偏亮偏黃，下面偏青偏暗 |
| 葉叢 | 聚成一團團有表面的葉叢 | 同樣聚成葉叢，不散成霧 |
| 光影 | 葉子的法線從樹冠中心往外，整團柔和受光 | 同樣 |

遠一點自動換成較少、較大的葉片（三層細節）。

## 二、八種樹

每種樹自己長枝幹，不是同一根樹幹變形；葉子各自重新造型；樹皮用原版的樹皮換色調和紋理比例。

| 樹 | 樹幹與枝 | 葉 | 樹皮 |
|---|---|---|---|
| **建木**（守護古樹） | 原版：扭轉的粗幹、懸空的盤根 | 原版全部葉子 | 原版 |
| **小建木** | 同上，三分之一大 | 同上，較疏 | 原版 |
| **樟** | 短幹，分成四五根大枝，樹冠圓 | 橢圓葉，深綠到黃綠 | 褐色，粗紋 |
| **楓** | 矮、斜，枝條往兩側平展，像一把傘 | 五裂掌狀葉，深紅到橘金 | 灰褐，平滑 |
| **銀杏** | 一根主幹直到頂，枝條短而平 | 扇形葉，金黃 | 灰褐，深縱紋 |
| **柳** | 粗短幹，枝往上彎，再垂下一簾簾細枝 | 細長葉，嫩黃綠 | 深灰，菱形深紋 |
| **梅** | 折角的虯幹，橫斜的枝，直挺的細枝 | 五瓣花（不長葉），粉到白 | 近黑，粗糙 |
| **柏** | 一根主幹，密而上揚的短枝，窄錐形 | 鱗片狀葉簇，深青綠 | 紅褐，細長條紋 |
| **枯樹**（病樹） | 扭轉的枯幹，斷枝 | 只剩十幾片捲起的枯葉 | 灰白 |

## 三、一個地方一兩種樹

不再每個地方都混全部的樹。每塊有主要的樹種和一兩種點綴；一片樹林只種一種。

| 地方 | 主要 | 點綴 | 溪邊 | 理由 |
|---|---|---|---|---|
| A1 青溪村 | 樟 | 梅（屋前屋後）、松 | 柳 | 村子裡有老樟樹，人住的地方種梅 |
| A2 河谷草地 | 松、樟 | | 柳 | 開闊的草地，一叢叢松和樟 |
| A3 溪岸 | 柳 | 樟 | 柳 | 水邊 |
| D3 上游溪谷 | 楓 | 松 | 柳 | 溪停了，整片秋紅，有一點蕭瑟 |
| D1 古林 | 柏 | （只有柏） | | 古老、深暗；一整片柏裡只有建木和那棵枯的柏不一樣 |
| 住處 | 松（山脊） | 梅 | | 自家的山坳 |

## 四、樹的由來

每個地方大量種某一種樹，都有原因：村裡有個說法或習俗，玩家一開始只當成風俗聽，後來才知道真正的原因。都用真的民俗或典籍當底，不刻字，由 NPC 隨口提起，或從樹的樣子看出來。

| 地方・樹 | 村裡的說法（玩家先聽到的） | 真正的原因（之後才懂） | 在哪裡揭開 | 典故 |
|---|---|---|---|---|
| **青溪村・樟** | 「青溪的老規矩：生了孩子，就在屋旁種一棵樟。等孩子出嫁、娶親，砍了做樟木箱。」可是村裡的老樟又多又大，一棵都沒砍過 | 那些孩子都在測資時被帶走了，沒有回來成親。樹一直長，沒有人砍。新人分到的空屋，旁邊都有一棵沒砍過的樟 | 祇苑（篩人是挑承天者） | 江南習俗：生女種樟，出嫁時砍樹做樟木箱當嫁妝 |
| **溪岸・柳** | 「有人要走，就折一枝柳給他。」溪邊的柳樹一棵棵都被折得禿禿的 | 柳＝留。三百年來每個離開青溪去測資的人，都有人折柳想留住他。柳知微姓柳 | 宗門篇（柳知微不見）、祇苑 | 折柳送別（灞橋折柳），「柳」諧音「留」 |
| **上游溪谷・楓** | 「上游那片楓林是血染紅的。很久以前有個罪人從這裡走過，把枷鎖丟在山上，枷鎖長成了楓樹。」 | 斷脈之夜以後，冥道的那一個把所有的罪攬在身上，往九夜走時經過這裡。被當成罪人的那個人，其實不是 | 九夜 | 《山海經・大荒南經》：楓木是蚩尤丟棄的桎梏所化 |
| **古林・柏** | 「古林的柏是守墓的。」林子中間那棵怪樹四周，圍著一圈七棵老柏，其中一棵枯了 | 七棵柏是那七個同學在斷脈之夜以後，為師父種的。枯的那一棵是冥道的那一個，他吊在九夜，三百年沒回來照顧過 | 既望或九夜 | 墓前植柏；松柏長青 |
| **住處・梅** | 茶亭老人給每個新人一株梅苗：「種著吧。哪天你要走了，折一枝寄回來。」 | 給遠方的人寄一枝梅，等於說「我還在」。終章，那些沒回來的人，有人託人寄回一枝梅 | 終章 | 陸凱〈贈范曄〉：「折花逢驛使，寄與隴頭人。江南無所有，聊贈一枝春。」 |
| **空屋後・銀杏**（提案） | 「這棵樹是祖父種、孫子才吃得到果子的。」整個新手世界只有這一棵 | 阿穗家的樹。金穗那棵靈獸化成的樹也是銀杏 | 金穗 | 銀杏又叫公孫樹：「公種而孫得食」 |

## 五、單棵的伏筆樹

都不刻字、不解釋，只讓「這棵樹不屬於這裡」被記住。

| 伏筆 | 在哪裡 | 玩家看到什麼 | 連到故事哪裡 |
|---|---|---|---|
| **建木** | D1 古林中間 | 一片柏和松裡，一棵完全不一樣的古樹：扭轉的樹幹，根懸在空中 | 世界觀：古林的守脈古樹是一株建木，「各地都有一棵，是同一種樹」；天工門在挖古樹的根（之後在根旁加挖過的痕跡） |
| **小建木** | 住處，屋子東邊 | 自家院子裡一株小樹，根也是懸空的，跟古林那棵一模一樣 | 不解釋。住處升級時跟著長大。到其他國家看到各地的那一棵，玩家會想起自家院子那一株 |
| **病樹** | 青溪村，停了的溪邊 | 一群活樹當中，只有它枯著，還掛著幾片枯葉 | 終章叫「萬木春」（劉禹錫：「沉舟側畔千帆過，病樹前頭萬木春」）。溪水重新流的那天，它發芽 |
| **一棵銀杏**（提案） | 青溪村，民居四（空屋）屋後 | 整個新手世界只有這一棵銀杏，金黃色 | 第一個要去的國家是金穗；靈道祖師的靈獸化成的那棵樹、阿穗的母親在樹下換藥。待 z1nnz 確認這間屋子是不是阿穗家 |

伏筆也記到 `docs/story/outline-v1.md` 的伏筆表。
