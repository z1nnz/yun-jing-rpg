# 地形與佈景標準：以璃月為參考 v1

> 2026-10-31，Claude Code。z1nnz：「上網查一下原神璃月的地形排版、佈置，以那個標準來做我們這邊。地形要有高低起伏，地面不要只有草，道路要不規則。」
> 參考：璃月的公開資料（官方開發者說明、地區介紹），以及 miHoYo 美術對璃月取材的說法：取自張家界、黃龍、桂林等真實山水，「貼近真實風景的奇幻」，以岩元素為主題所以偏暖色。
> 我們不照抄璃月的地貌，學的是它的**做法**。青溪是河谷村落，比璃月平緩，所以每條都換成我們的尺度。

## 一、璃月的六個做法

| # | 璃月怎麼做 | 為什麼有效 |
|---|---|---|
| 1 | **垂直層次**：石林、高崖、梯田一層一層往上，高低差把空間切成一區一區 | 站在任何地方都看得到「上面還有東西」，想往上爬 |
| 2 | **遠中近三景**：遠處是石峰剪影，中景是成叢的樹和岩，近景是腳下不同的地面 | 畫面有深度，不會只有一片綠 |
| 3 | **地標看得見**：每隔一段路就有一個遠遠就認得出的輪廓（石門、高塔、巨樹、亭子） | 不用看地圖也知道往哪走 |
| 4 | **路順著地勢**：路是彎的、有坡，石板路段和土路段交替，路邊有燈、碑、指路牌 | 路本身就是風景，也告訴玩家哪裡有人住 |
| 5 | **地面很多種**：草、乾草、泥土、碎石、裸岩、落葉、花叢交錯 | 近看有東西看，也暗示地形（濕的、陡的、常有人走的） |
| 6 | **暖色調、貼近真實**：赭石色的岩、金黃的樹、碧綠的水 | 有一種「東方山水」的統一感 |

## 二、換成青溪的尺度

| 做法 | 青溪怎麼做 | 現在的狀態 |
|---|---|---|

## 三、地面怎麼分（給做地形的人）

| 地面 | 出現在 | 規則 |
|---|---|---|
| 茂盛草地 | 平地的大部分 | 預設 |
| 乾黃草地 | 平地上一片一片 | 大尺度雜訊決定，和茂盛草地交錯 |
| 泥土路 | 路上、泥土平台 | 路寬加上沿路變化和邊緣鋸齒 |
| 石板 | 村裡的路段、廣場 | 只在村子（A1）；一段石板一段土 |
| 林下落葉 | 林地平台、溪岸上方 | 離溪 1–4 m |
| 溪邊碎石 | 水邊 | 離溪 0.2–1.6 m |
| 裸岩 | 陡坡 | 坡度大於約 25° |

草（地面上的立體草叢）只長在茂盛和乾黃草地上，路、碎石、裸岩上不長。

## 四、檢查表（每做一塊地都要過）

- [ ] 站在路中間轉一圈，每個方向都有層次（遠山、中景、近景）；
- [ ] 一眼看過去至少有三種地面；
- [ ] 路是彎的，有寬有窄；
- [ ] 跑 30–40 秒內會遇到一個值得停下的東西；
- [ ] 有一個從遠處就認得出的地標；
- [ ] 坡陡的地方看得出岩，溪邊看得出濕和石頭。
