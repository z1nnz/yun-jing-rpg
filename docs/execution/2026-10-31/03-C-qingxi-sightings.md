## 1. 一句話任務

- **第一部分**：把村民回應（#47）的模型細節做豐富、台詞改成村民自己的口氣。
- **第二部分**：在 A2 官道、A3 西溪和新手的家裡，藏 12 則「**見聞**」。
  - 每則是一件小道具加一段短短的文字；
  - 每一則都多說一點點這個世界的事，**但永遠不說破**。

## 2. 玩家會經歷什麼（見聞）

1. 走在官道上，路邊的草叢裡有一點微光，靠近才看得到（14 m 內才出現）。
2. 按 F 細看，是一件小東西：一枚舊鈴、一截斷掉的碑、一張被雨淋過的紙。
3. 跳出一張朱印卡片：標題，加上一兩句話。只寫看到什麼，**不解釋**。
4. 這件東西收進乾坤袋。回家以後，可以擺上屋裡的收藏架。
5. 找到幾則以後，玩家開始覺得：這些東西好像在說同一件事。

## 4. 和世界觀的關係（給你理解，**不能寫進遊戲文字**）

世界觀總綱裡有五層真相。新手這段只能碰到**第 1、2 層**，加上幾條長線的謎：

| 可以暗示的 | 例子（只是方向，不要照抄） |
|---|---|
| 第 1 層：溪底的靈脈在變弱 | 水邊的石頭是溫的；草只在某一條線上枯 |
| 第 2 層：三百年前縫過靈脈，有代價 | 很舊的工事遺跡；寫一半的契約；邊陲來的人留下的東西 |
| 前房客：這間舊宅以前住的人 | 一封沒寄出的信；牆上量身高的刻痕；被收好的一雙舊草鞋 |
| 長線的謎：缺月（像缺了一角的月亮的記號） | 刻在某個器物的不起眼處，**不解釋**，12 則裡最多出現 2 次 |
| 長線的謎：鴻篆（看不懂的上古文字） | 一塊碎石上的幾個字，玩家讀不懂；最多 1 次 |
| 世界很大：其他地方的旅人和東西 | 一枚八雲（遠方東邊）來的鈴、一片夕苑（遠方西邊）樣式的陶片。只寫外觀，不寫地名來歷 |

**規則**：
1. **不交代**：只寫看到、聽到、摸到的，**不說原因、不說「這代表什麼」、不預告**。
2. 每則標題 ≤ 10 字；內文 ≤ 60 字，一到兩句。
3. 用語照 `docs/standards/README.md` 第 3.2 節。
4. 每則在資料裡標它指向哪一層（只給我們看）。
5. 每則的道具名稱照**取名三層法**，在 README 寫出表面、典故、伏筆。
6. **不要寫成壞人**，也不要寫出「某某是兇手」這種話。

**寫法對照**：

| ✗ 不要 | ✓ 要 |
|---|---|
| 「這塊石頭是溫的，因為底下的靈脈正在甦醒。」 | 「石頭摸起來是溫的。四周的石頭都是涼的。」 |
| 「三百年前七宗在這裡縫合了靈脈。」 | 「碑上只剩半句：『……七家各出一人，至此……』後面被鑿掉了。」 |

## 6. 玩法與伺服器

在 `tools/qingxi-sightings-c/` 做一個可以操作的展示：
- **地圖頁**：A2、A3 的俯視圖上，玩家角色走動；靠近（14 m）才出現微光，按 F 跳出朱印卡片。
- **收藏頁**：已找到的見聞依找到的順序排列；點開可以重讀文字、旋轉看道具。
- **有條件的見聞**：展示裡可以切換「白天／夜晚／雨後」來測試。

**伺服器**（核心組做）：
- 見聞用現有的 `discover-fortune` 動作，每個角色只能拿一次；
- 你只要交資料（第 5 節）；
- **展示不發正式物品。**

## 7. 風格

- 每件都是「有人用過、有故事」的東西，不是新的。
- 和青溪河谷的配色一致；遠方來的東西（八雲的鈴、夕苑的陶片）可以有一點不同的樣式，但材質、筆觸和其他件一樣，看得出是同一個世界。

## 8. 驗收

- 共同標準（00-overview 第 4 節）全部做到。
- **12 件**：並排一張圖（看得出彼此不同）、每件四視圖、每件擺在世界裡的樣子一張（1.7 m 眼高）。
- **文字**：12 則全部列在 README，每則旁邊寫「指向第幾層」和三層取名；自己用第 4 節的規則逐則檢查，寫「符合／不符合」。
- **收藏尺寸**：每件都在 0.35 × 0.3 × 0.35 m 以內（`model_info.json` 寫實際尺寸）。
- **測試**：
  - 同一則不會拿兩次；
  - 有條件的見聞只在條件成立時出現；
  - 卡片文字不超過字數。
- **做完的定義**：不看說明的人玩展示，找到 5 則以後，會好奇「這些東西之間有什麼關係」，但說不出答案。
