## 4. 和世界觀的關係（給你理解，**不能寫進遊戲文字**）

- 世界觀的核心：靈脈會被活著的人「養」回來。
  - 玩家每收成一次，伺服器就悄悄記一點「脈息」；
  - 院角的舊石燈其實是一盞「**小天樞**」，撐著這一方水土，脈息越多它越亮。
- 這是玩家最早接觸到的伏筆之一：只看得到燈變亮，**永遠不說原因**。
- 這間舊宅以前住過一位客人（村裡的見聞「屋後的碎瓦」「空屋的門檻」提過他）。石燈底座可以刻一個很小、看不清的記號，像缺了一角的月亮（世界觀裡的「**缺月**」），不要放大、不要解釋。
- **取名建議**（照三層法）：石燈在資料裡可以叫「守燈」。
  - 表面：守夜的燈；
  - 典故：古代守燈人徹夜不讓燈滅；
  - 伏筆：它守的是這一方水土。
  - 你有更好的名字可以提，在 README 寫出三層。

## 6. 玩法與伺服器

在 `tools/territory-backyard-a/` 做一個可以操作的後院展示。

**要做的**：
- 走進後院，在兩塊田種青靈草或淨水蓮。
- 時間可以加速（例如按一個鍵快轉），看四個生長階段。
- 成熟後收成；每收成一次，石燈亮一段（最多 4 段）。
- 柴門可以開關。
- 晾藥架收成後自動掛上草藥（只是畫面）。

**生長階段怎麼算**（核心組會照這個接進遊戲，請照做）：
- 生長進度 `t` 從 0 到 1（種下 = 0，可以收成 = 1）；
- 階段：`t < 0.25` 嫩芽、`0.25 ≤ t < 0.6` 幼株、`0.6 ≤ t < 1` 成株、`t ≥ 1` 成熟；
- 淨水蓮用同樣的門檻。

**伺服器**（核心組做，你不用做）：
- 種植、收成已經有了（`plant`、`harvest`，新手可以種兩塊田）。
- 「脈息」已經有了：每次收成加一，現在不顯示給玩家。
- 石燈亮度 = 由脈息換算的 0–4 段，換算方式核心組定。
- **展示裡的種植和收成只在本機，不發正式物品。**

## 8. 驗收

- 共同標準（00-overview 第 4 節）全部做到。

- **石燈**：五段亮度並排，白天、夜晚各一張。
- **後院**：1.7 m 眼高從後門看出去一張、從院子盡頭看回屋子一張、俯視一張（標格位 ID）。
- 測試：
  - 生長階段門檻；
  - 重複收成不重複加亮度；
  - 柴門開關不卡住玩家。
- **做完的定義**：不看說明的人走進後院，能種下、等它長大、收成，並注意到石燈變亮了。
