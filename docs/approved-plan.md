# 雲境設計基準

只記錄已確定方向。未完成情況以 [status.md](status.md) 為準。

## 產品

- Unity 原生手機橫向 App 為主，Windows 共用角色與規則。
- 分區多人世界；私人洞府與部分宗門內容採個人實例。
- 樹伴為獨立產品，只能透過受限介面連動。
- 不製作人格、聲音或逝者代理。

## 創角與前十日

- 創角時由伺服器分配靈根、體質、靈竅等先天資料，不能重抽。
- 先天差距是真實優勢；天才不附加等值懲罰。
- 玩家先取得《煉氣訣》，可自由修煉、採集、狩獵、交易與探索。
- 創角滿十個現實日後永久開放正式測資，離線也計時。
- 第十日前不安排每日必做或固定宗門介紹；宗門線索由玩家探索。
- 凡骨可立即練體，之後可持續體修或尋找後天開靈路線。

## 宗門與修行

- 宗門由開發團隊建立，玩家不能控制他人的核心資源。
- 高資質可由內門起步；普通資質可由雜役或外門晉升。
- 入宗後取得洞府、床、箱子與靈田。
- 靈根與體質影響學習效率，不鎖死宗門或修行方向。
- 技藝都能學；專精依長期實作、參悟、師承與材料累積。
- 首版主要戰鬥方向為劍修、體修、法修；PvP 僅雙方同意切磋。

## 秘境

- 入宗後才開放。
- 每週從已測試模板產生 1–3 個候選，由營運覆核宗門、境界、角色年齡、獎勵與時間後發布。
- 暫定週五公告、週六 20:00 開門，每次進場約一小時。
- 不同秘境可限不同宗門，名單可以重複或全宗門開放。
- 不把唯一突破資格只放在單一固定時段。

## 經營與多人

- 洞府包含靈田、丹房、器坊、靜室、水路、陣眼與靈獸設施。
- 技藝包含靈植、煉丹、煉器、陣法、符篆與御獸。
- 普通材料可交易；突破領悟、個人試煉及宗門貢獻不可轉讓。
- 所有資產變更由服務端決定；重送、並行與重啟不能重複發獎。
- 世界活動採個人資格，不讓大宗門、公會或最後一擊壟斷。

## 商業與製作

- 不賣出生重抽、靈根、突破保證或永久戰力。
- 自製模型必須先生成、檢視並保存 AI 三視圖，再開始建模。
- Unity、網路與內容版本固定；未通過 Editor、真機或多人測試的內容不得宣稱完成。
