# 《雲境》產品、玩法與三人開發分工 v0.3

狀態：審閱草案  
日期：2026-10-25  
目的：先決定遊戲平台、完整玩法骨架及三人工作邊界，再擴建正式場景與內容。

本文件是下一階段的提案，不代表所有功能已實作。現況仍以 [status.md](status.md) 為準。

## 一、產品形態

### 決策建議

《雲境》採用：

> **手機橫向 App 為主要版本，Windows 為同帳號、同角色、同世界的高畫質版本。**

不把完整遊戲製作成瀏覽器 Web 遊戲。網頁只負責：

- 官網、公告、活動日曆與版本資訊。
- 帳號綁定、裝置管理及客服入口。
- 角色和洞府的只讀展示；未來可做不影響戰力的輕量操作。
- 營運後台，不提供一般玩家存取。

### 為什麼以 App 為主

| 面向 | 手機 App＋Windows | 完整 Web 遊戲 |
|---|---|---|
| 3D 畫面與效能 | 可直接控制畫質、記憶體、Shader、資源分包 | 瀏覽器記憶體、載入、相容性限制更多 |
| 操作 | 手機觸控、手把、鍵鼠分別調校 | 瀏覽器輸入、全螢幕與焦點管理更複雜 |
| 大型素材 | 可按州域下載、背景更新 | 首次載入和快取管理較難穩定 |
| 跨平台 | Unity 共用主要規則與素材 | 仍要另外處理 WebGL 限制與伺服器相容性 |
| 長期營運 | 推播、更新、裝置驗證較完整 | 適合展示與輕量玩法，不適合本作主體 |

### 裝置定位

- 手機是最大多數玩家的主要入口，30 FPS 是基準，60 FPS 是高階選項。
- Windows 提高解析度、陰影、視距、植被與特效，不改變碰撞、掉落或戰鬥規則。
- 同一角色同時只允許一個可操作連線；換裝置時交接控制權。
- 手機可完成全部核心內容，不把精準戰鬥或高階副本限定在 PC。

## 二、遊戲一句話與核心承諾

> 玩家帶著真正不同的先天資質進入共同修仙世界，先以普通人的方式謀生與修行，十日後接受測資並加入宗門，再透過戰鬥、經營、研究、師承、秘境與合作走出自己的道路。

四項核心承諾：

1. **出生真的不同。** 天才有實際優勢，凡骨也有內容完整但更艱難的路。
2. **修行不是單純刷經驗。** 境界需要功法掌握、身體條件、材料準備及實際試煉。
3. **生活系統支撐修仙。** 種植、煉丹、煉器、陣法、符籙與御獸都能改變探索和戰鬥。
4. **世界有人共同生活。** 玩家會相遇、合作和留下建設成果，但不讓大公會壟斷個人進度。

## 三、完整玩家旅程

### 階段 0：創角與隱藏先天

玩家自訂外觀後建立唯一修行身分。伺服器在同一交易內完成：

- 隨機分配先天靈根、體質、靈竅及初始身體狀態。
- 保存不可重抽的出生紀錄。
- 配發基礎衣物、工具、少量靈石與《煉氣訣》。
- 設定創角時間；滿十個現實日才開放正式測資，離線也計時。

十日前只告訴玩家可以做什麼，不揭露精確品質和稀有度。玩家能從實際修煉感覺到差異，但不能用介面反覆探測後換帳號。

### 階段 1：第 1–3 日，先活下來

所有人從「青溪山院」共同聚落開始：

- 取得暫住床位、基礎箱子及修煉位置，不提前配發正式洞府靈田。
- 學習移動、採集、基礎武技、引氣與物品使用。
- 凡骨無法正常引氣，但能立刻走鍛體、負重、藥浴準備和武技路線。
- 可採普通草藥、木材、礦石；狩獵山兔等低級獵物。
- 把材料直接出售、交委託，或留作煉製。

第一小時必須讓任何資質都能完成一件有意義的事：第一次採集、第一次戰鬥、第一次交易，以及青溪異常的第一個線索。

### 階段 2：第 4–6 日，建立生存方式

玩家開始形成自己的日常循環：

- 居家修煉或外出採獵。
- 學習一項基礎技藝：靈植、煉丹、煉器、陣法、符籙、御獸。
- 接觸青溪斷流事件，選擇生態、修陣、御獸或戰鬥方向。
- 透過交易和委託換取修煉丹藥、武器、工具及情報。
- 見到其他玩家參與共同水渠、橋梁或藥圃工程。

這階段讓玩家理解「資源不是只有刷怪」，並讓不同天賦的人開始有不同優勢。

### 階段 3：第 7–9 日，認識宗門

七宗門在聚落開設公開課、功法演示與模擬選比：

- 太玄道院：綜合功法和轉修彈性。
- 問劍山：劍勢、距離、御劍及本命劍。
- 玄岳宗：體修、氣血、格擋、藥浴及護體。
- 丹霞谷：靈植、藥性、丹藥及調理。
- 天工門：煉器、陣法、符籙及工程。
- 御靈谷：靈獸習性、共生、偵察和棲地。
- 玄冥宗：特殊能量、濁息及高風險功法控制。

玩家可以嘗試方向，不因試玩便自動入宗。第九日前提供一次選比模擬，清楚說明可能獲得的身分與起步條件。

### 階段 4：第 10 日，廣場測資與宗門選比

完整流程：

1. 在測資廣場啟動中央測靈晶石。
2. 揭露出生紀錄，說明靈根、體質、靈竅、經脈及目前修行狀態。
3. 七宗門依自己的傳承評估適性，不給全服唯一戰力分數。
4. 玩家完成與方向相符的基礎試煉。
5. 顯示各宗門願意給予的起始身分：雜役、外門或內門。
6. 玩家自己選擇去哪個宗門；高資質不強制選擇最高待遇。

宗門沒有招生名額，不由玩家會長審核。低資質者可從雜役或外門晉升，不被永久封鎖傳承。

### 階段 5：入宗與正式洞府

首次入宗一次性取得：

- 私人洞府空間。
- 床、箱子、修煉蒲團與基礎工作台。
- 一塊可種植靈田。
- 宗門服飾和起始功法資格。
- 第一批個人任務及貢獻取得方式。

宗門大殿、課堂、坊市、演武場等公共區多人可見；私人洞府預設個人實例，未來可邀請訪客。玩家能看到宗門總弟子、近期活躍與目前在線，不把總帳號數偽裝成現場人數。

### 階段 6：長期修行

長期遊玩由六條互相連接的線組成：

- 境界：煉氣／淬體 → 築基／體修築基 → 結丹／體丹。
- 師承：導師、功法、掌握、轉修與個人傳承。
- 洞府：靈田、水路、丹房、器坊、陣眼、棲地和布置。
- 技藝：材料研究、可靠配方、委託生產和專精。
- 世界：青溪、斷脈遺跡、宗門區域、野外危機和共同工程。
- 秘境：限時探索、路線取捨、資源風險和撤離。

## 四、核心玩法循環

### 每 5–10 分鐘

- 收成、安排生產、補充修煉資源。
- 接受或交付一項委託。
- 調整功法、裝備、靈獸或洞府供能。
- 查看今日秘境、宗門課程及朋友狀態。

### 每 20–40 分鐘

- 完成一次野外探索或採獵路線。
- 推進一段師承或宗門任務。
- 研究一個配方、修一段水渠或處理區域事件。
- 與 1–4 人完成一個可調整規模的遭遇。

### 每 60–90 分鐘

- 限時秘境。
- 突破試煉。
- 12 人公共危機或大型共同工程。

### 每週

- 秘境模板與宗門入口輪替。
- 宗門教學、研究委託和世界危機更新。
- 山院共同工程出現新階段，但不清除個人已完成成果。

不採連續登入懲罰；玩家缺席幾天，作物成熟後保留，角色不會因現實時間老死。

## 五、先天與後天成長

### 出生層級測試表

| 類型 | 機率 | 實際影響 |
|---|---:|---|
| 凡骨 | 10% | 無先天靈根，先走體修、藥浴、武技或後天開靈 |
| 常資 | 76.97% | 能正常修行，選擇與資源配置最重要 |
| 良才 | 10% | 較佳吸收、靈竅或適性組合 |
| 天驕 | 3% | 明顯更快、更早承載高要求功法 |
| 天命 | 0.03% | 極稀有頂級組合和專屬體質 |

出生不是一個總戰力數字，而是六組資料：靈根、體質、靈竅、經脈、丹田／氣海、先天特性。

### 後天改變

- 凡骨可以一路體修，也可完成長期事件取得後天靈根。
- 靈竅可以開啟，經脈可以修復和強化。
- 體質可調理與淬鍊，但不能廉價複製別人的先天專屬體質。
- 天才保留實際速度和容量優勢，不用隱藏懲罰硬把所有人變成一樣強。
- 核心進度不放在極低機率世界王掉落或玩家公會分配中。

## 六、修行與突破

突破由三部分構成：

1. 準備：修為、材料、身體及裝備狀態。
2. 掌握：功法熟練、經脈配置、淬體或技藝成果。
3. 試煉：路線對應的操作與判斷。

失敗要告訴玩家原因並給修復路徑，不用「材料全扣後隨機失敗」。失敗不重抽天賦、不清空境界、不永久破壞帳號。

| 路線 | 突破偏重 |
|---|---|
| 劍修 | 劍勢控制、破綻判斷、本命劍共鳴 |
| 體修 | 氣血循環、承壓、藥浴和身體控制 |
| 法修 | 元素順序、經脈運轉、環境導能 |
| 生產專精 | 材料理解、穩定工序、以技藝解決試煉條件 |

首個正式版本做到結丹等價境界。元嬰、化神保留世界設定，不先空做大量上層內容。

## 七、戰鬥

### 手機操作基準

- 移動、鏡頭、普通攻擊。
- 一個閃避／防禦操作。
- 兩個功法技能。
- 一個本命技能。
- 一個快捷消耗品。

提供目標鎖定、輔助瞄準、鏡頭減震、按鍵調整。PC 和手把仍使用相同技能容量，避免 PC 因多十個快捷鍵取得規則優勢。

### 戰鬥差異

- 劍修：距離、劍勢、破綻、御劍和劍陣。
- 體修：格擋、反擊、壓制、救援和承受環境傷害。
- 法修：元素狀態、施法順序、範圍控制和環境改變。
- 魔道功法：與主修組合，以濁息換短期力量，需要控制與調理，不等同惡意 PK。

敵人以動作、聲音和地面提示表達威脅。合作貢獻包含傷害、控場、護陣、救援和環境操作，不採最後一擊獨占。

首版只有雙方同意的切磋，不做強制野外 PK。大型 PvP 是否加入，待核心 PvE 與經濟穩定後再決定。

## 八、技藝、洞府與經濟

### 六種技藝

| 技藝 | 主要決定 | 支援玩法 |
|---|---|---|
| 靈植 | 品種、土壤、水源、鄰植、採收 | 丹藥、藥浴、環境修復 |
| 煉丹 | 藥性、配比、火候、用途 | 修行、治療、調理 |
| 煉器 | 材料、結構、器紋 | 武器、工具、洞府設備 |
| 陣法 | 節點、連接、供能、範圍 | 生產、戰鬥、解謎 |
| 符籙 | 效果、觸發條件、容量 | 一次性戰術和探索工具 |
| 御獸 | 習性、接近、培養、指令 | 偵察、戰鬥、洞府工作 |

材料共用屬性、材性／藥性、純度、穩定性，避免六個系統各有互不相干的稀有度。

### 洞府資源

水量、靈氣、土壤、陣法承載與工作位互相競爭。擴建是新的配置選擇，不只增加數字。訪客能使用主人允許的設備；採收、搬走物品和拆建築需要明確權限。

### 經濟

- 靈石是主要交易媒介；靈礦不直接無成本變成貨幣。
- 普通材料與成品可交易；突破領悟、個人試煉及宗門貢獻綁定。
- 固定價格刊登與託管代煉先上線，不先做全服競標拍賣。
- NPC 提供基本服務，沒有玩家接單時也不封鎖核心進度。
- 修理不降低裝備永久上限。
- 首版不開玩家直接送大量靈石和自由丟物，降低刷號洗資產。

## 九、秘境

秘境不是只有一條路打王，而是「一小時內判斷風險、尋找機緣並安全帶出成果」。

每個秘境包含：

- 入口條件：宗門、境界、角色世界年齡、場次、個人次數。
- 探索時計：約一小時；提前撤離可保存已結算成果。
- 多條路線：穩定材料、危險機緣、解謎捷徑、合作工程。
- 資源負重：帶得越多，撤離風險和選擇越重要。
- 死亡規則：不掉入場前財產；秘境內未封存收益部分損失，具體比例待定。
- 單人和 1–4 人都能完成基本目標；多人提供不同解法。

第一批只製作：

1. 通用「青溪藥谷」：採藥、生態、濁氣和低級妖獸。
2. 宗門「斷脈古府」：修陣、偵察、戰鬥及撤離。

驗證玩法成立後，再用模板輪替條件與事件，不一次量產五張空洞地圖。

## 十、多人世界與防壟斷

| 空間 | 規模 | 作用 |
|---|---:|---|
| 私人洞府 | 主人；訪客後續開放 | 生產、布置、閉關 |
| 山院 | 24 名固定居民；每分線 12 人 | 鄰居、公共工程、日常相遇 |
| 宗門、坊市、野外 | 每分線 12 人 | 教學、交易、探索、活動 |
| 小隊秘境 | 1–4 人 | 完整遭遇與分工 |
| 公共危機 | 每場 12 人 | 妖獸、靈脈與環境危機 |

- 宗門由開發者建立，玩家不能創建控制核心資源的宗門。
- 山院沒有玩家會長，不由玩家扣住獎勵。
- 世界王按個人資格發獎，不看最後一擊或傷害排名。
- 核心突破材料有個人穩定路徑。
- 好友優先同線；滿員時整隊進另一條分線。
- 不活躍山院可搬遷，個人洞府和資產跟隨角色。

## 十一、樹伴連動

連動可選，不是遊戲必需品：

- 樹伴種植長週期靈草，可輸送到自己綁定的《雲境》角色。
- 接收有連續 28 日上限，原料和衍生成品維持綁定。
- 提供省時與穩定性，不直接增加永久靈根、不替代突破試煉。
- 不使用樹伴仍能在遊戲內取得同級用途材料。
- 遊戲和樹伴後端、資料庫、憑證保持獨立。

這項功能要等資產帳本、重送、防複製及取消流程驗證後才開放。

## 十二、美術與大世界方向

已選方向：

- A「暖陽河谷」的清楚地圖骨架。
- D「古木青溪」的生活、靈植與濕地氣質。
- B「雲瀑山門」作為遠方宗門及後續山門區。
- C「斷脈靈湖」作為稀有世界奇觀和中後期主線區。

初期大世界採分區而非真正全服無縫地圖：

1. 青溪山院與測資廣場。
2. 聚落坊市及暫住區。
3. 靈草濕地與教學藥圃。
4. 竹林採集區。
5. 低級狩獵丘陵。
6. 青溪斷流上游。
7. 宗門渡口／山門遠景入口。

每區先定玩法、尺度、玩家密度與效能預算，再做地形和資產。自行製作任何物件，仍須先生成、檢視及保存 AI 三視圖後再建模。

## 十三、首個可玩版本範圍

### 必須完成

- 一個共同聚落和五個相連小區域。
- 創角、隱藏出生、十日計時、測資廣場。
- 凡骨和普通修士兩條可走通路線；稀有資質用測試身分驗證。
- 體修與法修的基礎戰鬥；一種低級敵人。
- 採集、交易、靈植、煉丹和簡單陣法。
- 太玄與玄岳兩個宗門教學入口。
- 入宗配發洞府、床、箱子與一格靈田。
- 青溪斷流的 30–60 分鐘完整體驗。
- 1–4 人合作，重登後成果仍在。

### 先不做

- 七宗門全部完整場景。
- 元嬰、化神及上界。
- 強制 PvP、大型宗門戰和玩家創宗。
- 全服無縫大地圖。
- 大規模寵物繁殖和遺傳系統。
- 完整自由建築、玩家土地圈占。
- 真人唯一性的虛假保證。

## 十四、三人分工

目前以三個實際角色規劃：使用者、Codex、`@joshsu54`。如果日後再加入真人協作者，再從下面工作包拆出，不改變責任邊界。

### 使用者：世界與核心體驗總負責

你負責最核心、最難拆分、最需要整體判斷的部分：

- 決定遊戲方針、世界氣質、宗門性格和最終取捨。
- 負責初期大世界的總布局、動線、區域關係和地標比例。
- 親自處理或主導測資廣場、古樹、青溪核心、主山門等主要／高難度模型。
- 決定主線事件、關鍵 NPC、戰鬥手感和畫面品質是否符合想像。
- 驗收可玩版本；決定什麼能進 main、什麼要重做。
- 處理玩法與建模互相衝突時的最終方案。

Codex 會替你建立工具、腳本、測試、規格及技術驗證，降低你處理最難內容時的重複工作。

### Codex：玩法與工程負責

專注把規則做成可靠、可測、可連線的遊戲：

- 出生、十日計時、宗門、境界、功法、技藝、秘境、任務與經濟規則。
- 伺服器權威、資料庫、資產帳本、防重複、登入與跨裝置存檔。
- Unity 互動程式、戰鬥原型、API、開發工具和自動測試。
- 每個玩法提出模型需求單：尺寸、碰撞、骨架、動畫、狀態、LOD 及交付日期。
- 把模型和資料接入實際互動，做錯誤處理與驗收腳本。
- 安全依賴、CI、版本鎖定和技術文件。

Codex 不擅自改掉已確認的出生差距，也不把未經 Unity 編譯／真機測試的內容宣稱可用。

### `@joshsu54`：建模與美術資產負責

專注大量可拆分、可驗收的美術生產：

- 人物、NPC、低級妖獸、武器、道具、建築模組、洞府家具、植被和環境物件。
- 模型清理、UV、材質、貼圖、骨架、動畫、LOD、碰撞代理及匯出。
- 整理現有 `dondon2.0` 素材，依交接清單放進 `art/incoming/dondon`。
- 每個資產附來源、版本、三視圖、比例、面數、動作和已知缺項。
- 依玩法需求單交付，不自行替玩法增加未討論的判定規則。
- 修正 Unity 匯入後發現的比例、法線、材質、骨架和效能問題。

### 一項功能如何跨三人流動

以「山兔狩獵」為例：

1. Codex 定義玩法：移動、警戒、受擊、死亡、掉落、伺服器判定和所需動畫。
2. 使用者確認體驗：山兔速度、難度、狩獵區動線與美術氣質。
3. `@joshsu54` 依需求完成模型、骨架、Idle／Run／Hit／Death 動畫、LOD 和碰撞代理。
4. Codex 接進 Unity 和伺服器，完成測試。
5. 使用者實際遊玩並驗收手感；問題回到原負責人，不互相覆蓋檔案。

以「測資廣場」為例：

1. 使用者與 ImageGen 確定三視圖及主體比例。
2. 使用者主導高難度主體模型；`@joshsu54` 可承接地磚、柱、材質與 LOD 模組。
3. Codex 完成十日資格、測資互動、伺服器結果和動畫觸發。
4. 三人一起在 Unity 內驗收比例、鏡頭、效能與流程。

## 十八、需要使用者審定的方針

本版建議先採以下預設；你可逐項修改：

1. 平台：手機 App 主版＋Windows 同步版；不做完整 Web 遊戲。
2. 大世界：A 河谷結構＋D 古林氣質；B 宗門、C 斷脈後續區。
3. PvP：首版只有雙方同意切磋。
4. 秘境死亡：不掉入場前資產，損失部分尚未封存的秘境收益。
5. 年齡：使用角色世界年齡，不直接使用真人生日；具體時鐘另定。
6. 宗門：官方七宗門，玩家不創立控制資源的宗門。
7. 首版宗門：先完整太玄與玄岳，其餘做演示和世界存在感。
8. 首版境界：做到結丹等價，不先做元嬰／化神。
9. 三人分工：使用者負責最難的世界與主體；Codex 負責玩法工程；`@joshsu54` 負責大量建模資產。

上述方針審定後，才把工作包轉成 GitHub Issues、里程碑和實際排程。
