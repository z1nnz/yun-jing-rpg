# 《承天》遊戲整體架構 v1

> 遊戲名稱《承天》；世界名稱「不周」；「雲境」是天缺下方的一個區域（2026-10-29 定案）。

> 2026-10-29，Claude Code 把 z1nnz 這一天的決定整理成一張完整的架構：
> - 多人的新手大世界；
> - 每個新手從第一天就有自己的領地；
> - 入宗後由宗門分派住處；
> - 稀有機緣；
> - 埋伏筆的主線；
> - 「原來我們在改變這個世界」的世界觀。
>
> 這份回答「整個遊戲怎麼拼在一起」。
> - 細節在各專門文件，入口是 [製作規範總綱](standards/README.md)；
> - 原本的 [遊戲製作總綱](game-production-bible.md) 仍然有效（核心體驗、公平、角色客製），這份把它和新決定接起來。

---

## 1. 一句話與三根柱子

**在一個浮在雲海上、正悄悄裂開的仙俠世界裡，從凡人開始修行。你在自己的地上種下的每一株靈草，都在一點一點把世界縫回來。**

| 柱子 | 意思 | 主要靠什麼 |
|---|---|---|
| **修行的手感** | 採藥、練功、煉丹，每一下都有回饋 | 演武區、煉丹台、領地的田 |
| **一起探索的大世界** | 和其他新手一起走、一起遇見、一起改變世界 | 多人大世界、見聞與機緣、世界事件 |
| **原來如此的世界觀** | 伏筆一層一層揭開，最後發現自己的日常有意義 | [世界觀總綱](story/world-lore-v1.md) 五層真相、脈息 |

## 2. 世界觀怎麼撐起整個遊戲

世界觀不是背景故事，它決定了玩法為什麼存在：

```text
天缺 → 代天大陣撐住天 → 陣在壞、靈脈在裂
                                │
         ┌──────────────────────┼──────────────────────┐
     自己的領地               共用的大世界            宗門與秘境
  種靈草＝養地下的靈脈      修水路、淨化、狩獵      宗門的秘密、裂口
  （個人脈息）              （區域脈息、世界事件）    （真相第 3–5 層）
         └──────────────────────┼──────────────────────┘
                                ▼
            全服的脈息決定下一季世界的樣子（結局由玩家一起寫）
```

## 3. 空間結構

### 3.1 新手期（第 1–10 天）

```text
     ┌───────────┐   推門出去     ┌──────────────────────────────┐
     │ 自己的領地 │ ─────────────▶ │ 新手大世界（多人、分線）       │
     │ 舊宅＋靈田 │ ◀───────────── │ A 青溪 · D 古林 · B 山城 · C 湖 │
     │ ＋練功處   │   隨時回家      │ 外緣是雲海斷崖                 │
     └───────────┘                └──────────────┬───────────────┘
                                                  │ 第 10 天測資
                                                  ▼
                                             選擇宗門（宗門很多）
```

### 3.2 入宗後

```text
  宗門分派的住處（個人） ⇄ 宗門（同門共用） ⇄ 州域（更大的多人世界） ⇄ 秘境（組隊，每週）
            ▲
     新手領地的作物與收藏搬過來（暫定）
```

### 3.3 三種空間的分工

| | 領地／住處 | 大世界 | 秘境 |
|---|---|---|---|
| 人數 | 1 人 | 每線約 30–50 人（K19 決定） | 1–4 人 |
| 場景 | 獨立小場景，進門載入 | 區塊串流（100 m 一塊，45 m 載入、90 m 卸載） | 獨立場景 |
| 狀態 | 個人資料（田、建築、收藏） | 共用世界狀態（溪水、古樹、限量機緣）＋個人進度 | 一次性 |
| 玩法 | 種植、練功練氣、閉關、煉丹、佈置 | 探索、採集、狩獵、見聞、機緣、主線、世界事件 | 挑戰、真相片段 |

## 4. 時間結構（玩法循環）

| 尺度 | 循環 | 例子 |
|---|---|---|
| **一次上線**（15–40 分鐘） | 回家 → 出門 → 回家 | 收成、補種 → 練一輪功 → 出門採藥、追靈獸、找見聞 → 回家煉丹、種下新的 |
| **一天** | 作物成熟、時辰變化 | 清晨才開的靈花；夜裡的第三盞燈；田裡隔天收成 |
| **新手十天** | 序章 → 第一章 → 第二章 → 測資 | 離線也計時；第 10 天測資、選宗門 |
| **每週** | 裂靈湖秘境開一次 | 每次揭露一段「斷脈之年」 |
| **每季** | 世界走向 | 全服脈息、濁氣、大陣強度決定下一季的世界 |

## 5. 成長線（玩家在變強什麼）

| 線 | 怎麼長 | 誰決定 |
|---|---|---|
| 資質 | 出生時一次決定，不能重抽；斷脈之體極稀有 | 伺服器 |
| 修為 | 練氣（引氣）、練體（體修）、功法 | 伺服器結算每次練功 |
| 技藝 | 種植、煉丹、製器 | 伺服器（配方、品質） |
| 收藏與見識 | 見聞、機緣、殘卷 | 伺服器（限量、條件） |
| 世界貢獻 | 脈息（玩家看不到，真相揭曉時才攤開） | 伺服器 |
| 真相 | 解鎖世界觀的層 | 主線進度＋機緣 |

## 6. 系統地圖

```text
用戶端（Unity，網頁 PWA＋Windows）
 ├─ 場景：產生器從資料生成（青溪村、區塊、領地）、區塊串流
 ├─ 互動：採集、練功、煉丹、種植、見聞、門
 ├─ 介面：玉紙墨銅 HUD、觸控、旅途手札、乾坤袋
 ├─ 演出：練功鏡頭、音效、天氣時辰
 └─ 連線：GameApi（REST，結算）＋ 即時同步（K19，看到彼此）
                 │
伺服器（NestJS）
 ├─ 帳號與角色：出生資質、旅程（第幾天、住處種類）
 ├─ 動作結算：每個動作一個 case，requestId 防重複
 ├─ 世界狀態：水路、古樹、限量機緣、區域脈息（K22、K20）
 └─ 多人房間：分線、人數上限（K19）
                 │
內容資料（packages/content/*.json）
 └─ 物品、配方、宗門、見聞、機緣、主線章節、NPC 對話
```
