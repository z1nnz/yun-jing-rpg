# 缺月：七個方案，每個都從頭串到尾

> z1nnz：「缺月不夠悲壯，沒有使命感，可是每個人又有，真的好難寫。」「要讓我看到前後貫通所有故事的邏輯，我才能選得下去。」
>
> 每個方案都用同一組故事節點檢查，一格一格看它接不接得上。節點是 v5 已經定下、不想動的東西。

## 方案一：她（欠一個人的債，月亮就是她）

| 節點 | 怎麼接 |
|---|---|
| ① | 天缺張開，天往下塌，沒有人敢去扛。第一個飛升的人的女兒，把所有人的那一份都接到自己身上，一個人上了天 |
| ② | 每個人身上那一角，是她替你扛著的那一份留下的缺口。**所有人都欠她** |
| ③ | 扛了兩千年，她撐不住了。先人立大陣，替她分擔；「一人承天」是每一代派一個人上去，替她撐住正中心 |
| ④ | 她越來越虛弱，扛不住的那些份會掉回人間，落在某些人身上，那些人缺月就變深。太玄把他們帶走，是要把掉下來的份送回天上 |
| ⑤ | 師父是那一代上去替她撐的人。他撐不住，天就從他的錨（青溪）塌下來 |
| ⑥ | 戊辰年她幾乎碎掉，份掉得滿天下都是。那位女子把掉下來的份全收進自己身上，化進天缺，只留下最大的一份在嬰兒小滿身上 |
| ⑦ | 柳知微把孩子們身上掉下來的份接到自己身上；霽弦上了天，第一次見到她本人：一個三千年沒說過話的女孩 |
| ⑧ | **月亮就是她。** 她化成月亮守在天上，份一直掉，月亮就一直變瘦，三千年來越來越細 |
| ⑨ | 全服每個人把自己那一份接回來，三千年來第一次滿月，她第一次回到地上。驚喜：她是第一個飛升的人的女兒，天缺那一邊的父親終於見到她 |

- **悲壯**：高。一個人為所有人在消失。
- **使命感**：很高，是「還債」。
- **驚喜**：中。月亮是她，好猜。
- **弱點**：「一個女孩扛所有人」比較常見；她三千年不說話，角色要寫得好。

## 方案二：我們投了票（原罪）

| 節點 | 怎麼接 |
|---|---|
| ① | 天缺張開。太古每個人都有滿月紋，本來可以大家一起多扛一點，可是多扛就要少活、修為停住。在不周山下，所有人一起決定：**讓一個人去扛**。選的是第一個飛升的人的女兒，理由是「她父親闖的禍」 |
| ② | 每個人身上那一角，是那一天每個人舉起的那隻手留下的記號。我們都是舉手那些人的後代 |
| ③ | 千年前她撐不住，人們又做了一樣的選擇：把那一票寫成大陣的規矩，每一代挑一個人上去。**大陣就是那一票** |
| ④ | 太玄做的不是陰謀，是在執行全人類三千年前的決定 |
| ⑤ | 七人在青溪又被逼到同一個選擇：讓一個人（師父）沉下去，救所有人。只有冥道那一個說出口。他們重演了祖先的那一票，所以一輩子放不下 |
| ⑥ | 戊辰年那位女子是被「那一票」選上去的又一個人 |
| ⑦ | 柳知微做的，是三千年來第一次有人個別推翻那一票：把孩子的份接到自己身上，不讓任何孩子被選上去。霽弦在天上知道了全部，拆陣是想推翻那一票 |
| ⑧ | 月亮缺的那一角，是她被送上去那天，所有人一起從月亮上剪下來給她當座位的 |
| ⑨ | 全服又被問一次那個問題：誰去扛？這一次每個人都說「我來」。驚喜：斷章被撕掉的那一章，記的就是**我們**做的事 |

- **悲壯**：很高，而且是全人類一起的。
- **使命感**：很高，是「贖罪」。
- **驚喜**：最高。玩家一直以為太玄是加害者，原來全人類都是。
- **弱點**：比較黑。要寫成「祖先是害怕，不是壞」，才不會讓玩家覺得被指責；「沒有真正的壞人」還是成立。

## 方案三：還沒換崗的先鋒

| 節點 | 怎麼接 |
|---|---|
| ① | 天缺張開，各族每一家都派一個人，衝進天缺，用身體堵成一道牆，到今天還站在那裡 |
| ② | 缺月是「家裡有人還沒回來」的記號，每一家都有 |
| ③ | 牆上的人一個個倒下，牆越來越薄。大陣是給這道牆搭的架子；「一人承天」是派一個人上去守最薄的那一段 |
| ④ | 缺月深 = 你家站在牆上的那個人剛倒下，那一段空了，要你家的人去補。太玄是在「徵召」 |
| ⑤ | 師父守的那一段倒了，天從青溪塌下來 |
| ⑥ | 戊辰年牆破了一大段，那位女子一個人去堵 |
| ⑦ | 柳知微替孩子們躲徵召。霽弦上了天，看見的是一整片站了三千年的人 |
| ⑧ | 月亮缺的那一角，是從下面看上去的那道牆 |
| ⑨ | 全服上天換崗，三千年的祖先終於能回家。最大的畫面：一整支祖先的隊伍走下來 |

- **悲壯**：最高，是戰場的悲壯。
- **使命感**：最高，是「換崗」。
- **驚喜**：中。
- **弱點**：太像戰爭故事，和修仙、種田的溫暖調性比較遠；「徵召」有一點血統論的味道。

## 方案四：被忘記的人

| 節點 | 怎麼接 |
|---|---|
| ① | 天缺張開，有一個人上去扛。天的規矩是：扛天的人，**世上所有人都會忘了他**，因為還被人記著的人，會被這份牽掛拉回地上 |
| ② | 缺月是你心裡被挖掉的那個位置。三千年來扛過天的人太多了，每個家族都失去過一個想不起名字的人。每個人都說不出自己少了什麼，可是都少了 |
| ③ | 大陣讓一次只需要一個人上去，被忘記的人就少一點。「一人承天」本來是慈悲 |
| ④ | 缺月深 = 你最近才失去一個被忘記的人，洞還很大。洞大的人會開始「想起來」，一想起來，就會把天上那個人拉回地上，天就塌。太玄帶走他們，是怕他們想起來 |
| ⑤ | 師父十年前上了天，七個人**忘了他**，只覺得心裡空了一塊。斷脈之夜天塌下來，他們在青溪看見他的臉，才全部想起來，然後要親手斬下去 |
| ⑥ | 戊辰年那位女子，就是這條規矩最直接的例子：寒漪宮刻不出她的名字，瓦上沒有她的名字。小滿是她的女兒，身上那個洞最大，因為她失去的是母親 |
| ⑦ | 柳知微把孩子們心裡的洞藏起來，不讓大陣看見。她被收走以後，**沈岳也忘了她**，可是他每晚還是去點那盞燈，不知道為什麼。那張寫著他名字、旁邊一個「待」字的測資單，他看不懂是誰寫的。霽弦被帶走後，青溪也忘了他，只剩那封沒有署名的信 |
| ⑧ | 月亮缺的那一角，是三千年來所有被忘記的人。「缺角亮一下」是又有一個人被忘了 |
| ⑨ | 天變成大家一起扛，不再需要有人被忘記。全服同一刻，**所有人想起自己忘掉的那個人**：寒漪宮冰湖上的名字一個一個浮出來，沈岳想起柳知微。驚喜：斷章不是被人撕掉的，是那段時間扛天的人被全世界忘了，所以每個地方的歷史都缺同一段 |

- **悲壯**：很高，而且最私人：每個人都有一個想不起的人。
- **使命感**：高，是「把他們找回來」。
- **驚喜**：高。斷章、空白的名字、沒有署名的信全部同時解開。
- **和現有故事的貼合**：最好。戊辰年的女子、霽弦失憶、寒漪宮的空格、沒有名字的瓦，本來就都是「忘記」。
- **弱點**：「被所有人忘記」原神的大慈樹王用過，要寫出自己的樣子（重點放在沈岳點燈這種「忘了人、卻沒忘了做的事」）。

## 推薦：方案四 + 方案二（被忘記的人 + 我們投了票）

合起來是一條線：
1. **三千年前**：天缺張開，所有人害怕，一起決定讓一個女孩去扛（方案二）。天的規矩是扛天的人會被所有人忘記（方案四），所以投完那一票，大家就把她忘了，也把自己舉過手這件事一起忘了。**斷章**就是這樣來的：不是誰撕的，是那一段被全世界忘掉了。
2. **為什麼人人都有缺月**：每個人心裡都有一個被忘掉的位置；最早的那一個，是她。
3. **千年前**：大陣把那一票寫成規矩，每一代一人上去、一人被忘記。
4. **篩人**：缺月深的人洞最大、最容易想起來；一想起來，天上的人會被拉回地上。太玄帶走他們，是怕他們想起來。
5. **斷脈之夜**：七人忘了師父十年，天塌的那一刻才想起他，然後要親手斬他。
6. **戊辰年**：那位女子被忘得乾乾淨淨；小滿心裡的洞是母親。
7. **現在**：
   - 柳知微被收走以後，沈岳忘了她，卻每晚還是去點那盞燈；
   - 霽弦被忘了，只剩一封沒有署名的信。
8. **月亮缺的那一角**：三千年來所有被忘記的人。
9. **終章**：全服再被問一次「誰去扛」，這一次每個人都說「我來」。天變成大家一起扛，不再需要有人被忘記。所有人同一刻想起自己忘掉的那個人，沈岳想起了柳知微，月亮第一次圓了。

為什麼推薦這個：
- 悲壯、使命感、驚喜三樣都有：
  - 悲壯：每個人都失去過一個人；
  - 使命感：把他們找回來，也推翻三千年前的那一票；
  - 驚喜：一人承天是全人類選的，斷章是遺忘。
- 現有故事裡幾乎每一條線都已經在「忘記」上面，不用大改。
