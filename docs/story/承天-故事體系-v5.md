## 零、整個故事一句話

天本來是所有人一起扛的。有人飛升走了，把自己那一份留給下面的人，天就破了一個洞。三千年來，世界靠「讓一個人獨自承天」撐著。**《承天》講的是：一代一代獨自承天的人，和終於願意一起扛的我們。**

三條貫穿全篇的線：
| 線 | 是什麼 | 誰 |
|---|---|---|
| 天的線 | 天缺、大陣、承天者，三千年的真相 | 第一個飛升的人、歷代承天者、霽弦、小滿 |
| 約定的線 | 三百年前七個同學的盟約，和等他們回來的人 | 七人、小師妹、茶亭老人 |
| 我們的線 | 玩家這一代在青溪長大、散開、回來 | 玩家、同屆五人、柳知微、沈岳 |

## 一、世界的規則（所有故事都不能違反）

### 1. 天、承天、滿月紋
- 太古，每個人身上都有一輪淡淡的**滿月紋**，每個人扛一點點天，誰都不覺得重。修行只有一條道，叫**承天道**：修得越深，扛得越多，身邊的人就輕一點。
- 天的重量不會消失，只會**換人扛**。

### 2. 飛升與天缺
- 飛升是修到頂、離開這個世界。飛升的人帶不走自己那一份天，那一份落到天上「她」的身上（第十一節）。
- 每一次飛升都把天撕開一點。三千年前第一個飛升的人撕開的口子，就是**天缺**。

### 3. 天壓：飛升的代價由所有人付〔拍板〕
- 天缺越大，壓在所有人身上的「天壓」就越重：
  - **修煉變慢**：同樣的資質，三百年前的人比現在修得快，六十年前天裂以後又更慢了。所以老一輩的強者特別強，「今不如古」是真的；
  - **境界天劫變重**：每一次突破，天劫都比上一代更重。
- 天劫的輕重 = 天壓 × 這個人身上扛的天（缺月的深淺）。缺月深的人天劫特別重；天才走得越高，天壓也壓得越重。
- **和改版的關係**〔新〕：七地每解開一章，就有一位「停住的人」走完了路，天缺穩一點，**天壓鬆一點**。所以每個大版本提高境界上限，在故事裡有理由：不是開發者放寬，是世界真的變輕了。

### 4. 缺月：她替你扛著的那一份（第四版，詳見第十一節）〔新〕
- 三千年前，一個女孩把所有人的天都接到自己身上，上了天，化成**月亮**。
- 人人身上都有一彎淡淡的缺月：那是**她替你扛著的那一份**留下的缺口。所有人都欠她。
- 月亮從沒圓過，三千年來一直在變瘦：她一個人扛不動全部。
- 缺月深的人，心裡有一個很大的「想不起來的人」（第十一節的守夜人）。
- 靈氣、修煉照一般修仙世界的規則，和她無關〔拍板〕。

### 5. 代天大陣（千年前立）
- 扛天的人越來越少，天快塌了。先人把承天道拆成七條，各管一部分：**法、劍、體、丹、器陣、靈、冥**。七道合起來撐住一座看不見的大陣。
- 立陣那年，靈道把一頭上古巨鼇牽了出去，劍道斬下牠的四足，立在四方當新的天柱。這片地區叫**鼇極**就是這樣來的。玄岳宗世代守的那座山，是其中一條腿〔新〕。
- 大陣有兩條規矩，只有太玄道院的高層知道全部：
  1. **擋住飛升**：飛升劫由大陣把關，加到極難。
  2. **一人承天**：在測資時找出缺月最深的人，送上天缺，站到她身邊一起扛。上去的人會被地上所有人忘記，世人只知道「有人消失了」，連是誰都想不起來（第十一節）。
- 大陣每年要七位**道主**站上山城的天祭高台，用七道的信物重新「鎖」一次，否則會一年一年鬆開〔新：給七張面具一個非演不可的理由〕。

### 6. 太玄道院與「篩人」〔拍板：兩件事都做，院主是推手〕
- 太玄守著兩條規矩，所以「篩人」有兩件事：
  - **擋天才**：天才走得太快，遲早會去渡飛升劫。太玄在他們走到那一步以前，就讓他們「意外」止步（閉關不出、受傷、被派去遠地）；
  - **挑承天者**：測資時把缺月最深的人帶走。
- 現在的**太玄院主**是兩件事的推手。他溫和、公正、記得每個新人的名字，前期像導師一樣。他不是壞人：他親眼看過戊辰年天裂，死了一座城。他的選擇很冷，但從他的角度是對的。

### 7. 濁氣與濁獸〔建議〕
- 天缺會滲下**濁氣**，沉進地底的深淵，從靈脈的裂口冒出來。
- 被濁氣侵蝕的靈獸、器物、地脈之物叫**濁獸**，是戰鬥主要的敵人。打倒濁獸就是淨化，牠會變回原本的樣子離開。這和「照顧而不濫殺靈獸」一致。
- 冥道把濁氣收進自己身體，所以被當成邪宗。

## 三、三百年前：斷脈之夜（核心事件，重寫）

### 七個人與他們的師父
- 山城學宮有七個同屆的年輕人，一人走一條道，是最好的朋友。他們在學宮後山溪邊說：「以後誰當上道主，都要讓天下一起好。」
- 最強的那個是**青溪人**，走劍道，家裡有一個十五歲的弟弟。出門前他跟弟弟在溪邊說：「等我回來，我們一起把溪修好。」
- 他們的師父，十年前被挑去當了承天者。七個人一直不知道師父去了哪裡。
- 年紀最小的**小師妹**比他們小十歲，那一夜不在場。

### 那一夜
- 一位受人敬重的前輩渡過飛升劫，山城辦了三天的慶典。慶典最後一夜，天缺被撕大，師父撐不住了。
- 天往下塌。每一任承天者的重量都落在一個「錨」上，師父的錨就在**青溪的地底**。天要塌，是從青溪開始塌。
- 七人趕到青溪，第一次知道師父在哪裡。要救天下，只能把青溪那一段靈脈斬斷，讓它帶著師父和那份重量沉下去。
- 各人的反應：
  - **冥道**那一個：唯一說「斬」；
  - **法道**那一個：吼了一聲「你敢」。師父喊的那個字被一聲雷蓋住，她聽成了「站」（站到我後面，不准動手）；
  - **器陣道**那一個：當場佈陣要擋；
  - **丹道、靈道**：都說不要，卻都慢了一步，各自以為對方會攔；
  - **體道**那一個：一句話都沒說，閉著眼繼續撐；
  - **劍道**那一個：斬得斷的只有他。他的劍舉著，沒有落下。
- 冥道的那一個走過去，用冥道的術握住他的手，把那一劍斬了下去，同時把斬斷師父、斬斷家鄉的罪業全部引到自己身上。法道的雷同時落在冥道那一個身上。器陣道的陣碎了。
- 師父和青溪那一段靈脈一起沉下去。山城的慶典煙火還沒放完。
- 前一天，師父私下對冥道那一個說過：「明天如果我喊斬，他下不了手，你替他。他們會恨你。」只有他知道。

### 師父沒有死〔新〕
- 師父沉進了青溪的地底，還在下面，用剩下的力氣撐著那一段沒有塌下去。
- 青溪溪邊**溫溫的石頭**，「彷彿底下有什麼在呼吸」，就是他。
- 終章他被放下來的那一刻，石頭變涼，溪水從地底冒上來。

### 之後：縫脈與盟約
- 斬斷以後，剩下的靈脈要縫起來。七人在散之前合力縫了**縫脈陣**：
  - 把靈氣繞過被斬斷和受傷的地方，撐住大多數人住的地方；
  - 被繞過的地方從此慢慢枯，那就是**邊陲**。邊陲不是地圖上的邊，是一塊塊被繞過的補丁。青溪就是離山城最近的那一塊。天下最熱鬧的地方腳下，就是被犧牲的村子；
  - 裂靈湖是縫得最大的一道接口。
- 器陣道那一個在青溪的溪床上造了**水路陣基**，從上游把水引進來，讓青溪在靈脈斷了以後還有水。溪從此不再從地底冒上來〔拍板：溪停兩段〕。
- 七人在邊陲各村代表面前，在一張盟約上各蓋一個印：「等天穩了，一定回來把邊陲補好。」代表青溪去的，是那個十五歲的弟弟。他自願當盟約的擔保人：約定沒有兌現，他就走不了，印讓他一直活著。
- 之後六個人都不再跟冥道的那一個說話。

## 四、三百年間：七個地區、七條停住的路

### 小師妹：七張面具〔拍板：七位道主〕
- 七位道主一個個不見了，可是大陣每年要七位道主上天祭高台。少一位，大陣就鬆一點。
- 她一個人輪流戴七張面具，扮成七位道主，每年天祭站上高台，對邊陲的請願一概不回應，因為她不知道該怎麼回應。
- 各宗宗主、太玄院主都照常在位。他們每年只在天祭遠遠看見七位道主，從來沒有近看過。
- 她怕天下知道那一夜的實情會把玄冥宗滅門，用道主的身分把七個祖庭史書裡那一夜的記載全部撕掉。這就是**斷章**。玄冥宗還是被罵了三百年。

### 冥道為什麼只剩一個宗〔建議〕
冥道的宗門都在扛濁氣，一個接一個撐不住。剩下的在戊辰年被太玄封住九夜的出口，半個玄冥宗封死在深淵裡，從那年起只剩玄冥宗。

## 五、六十年前：戊辰年與「所謂伊人」

- 戊辰年的承天者是一位寒漪宮出身的女子。天裂開一大塊時，她為了補上那一塊，把自己化進天缺的邊緣，也把自己從所有人的記憶裡抹掉了。
- 補天之前，她在青溪住過一陣子，住的是後來霽弦住的那間屋子。村人全忘了她，只剩某個人在忘記之前，刻在瓦上的一句：「戊辰年，此屋曾住過一位客人。」**沒有名字**，因為刻的人已經想不起她叫什麼了〔拍板〕。
- 她有一個嬰兒。她把嬰兒和自己在天上的那一塊一起**封在缺月裡**，封一個甲子；把嬰兒抱到寒漪宮、沉進冰湖的，是一個戴面具的人（第六節）〔拍板：封在缺月裡沒長大／新：冰湖〕。
  - 寒漪宮每換一任承天者，才在冬至刻一個名字〔拍板〕。戊辰年那一格是空的，只刻了「所謂伊人」，因為她們想不起她是誰；
  - 冰底下有一個不會長大的孩子，寒漪宮也忘了為什麼。
- 今年又是戊辰，封印鬆開，嬰兒醒了。她就是**小滿**：
  - 不記得童年；
  - 說得出的家鄉，早就在戊辰年的天裂裡沒了；
  - 她跟著新人的隊伍走到青溪，總是在笑。

## 六、現在的人

### 霽弦：獨自承天的人，和戴面具回來的他〔拍板：參考克羅耶〕

**本體（這一代的承天者）**
- 約十五年前來青溪，住進那間屋子。他在屋後翻到那片戊辰年的瓦，開始追查那位沒有名字的客人〔拍板：霽弦也找到過它〕：
  - 寒漪宮的空格；
  - 史書裡被撕掉的那一章；
  - 缺月。
- 他越查越知道承天者是怎麼回事，也發現自己的缺月很深。
- 約十年前測資，柳知微藏不住他，院主把他帶去雲境。門檻下的信「待我測過資質，便回來」是測資前一晚寫的；名冊上寫「閉關未出」。
- 他現在在雲境，一個人撐著整片天。

**靈魂與肉體穿越時間（學克羅耶：靈魂回到過去、肉體被拋到別的時代）**

規則（內部用）：
- 天缺在時間之外。承天者扛的是補丁正中心，碰得到天缺的另一邊，所以他的**靈魂**和**肉體**都可能被天缺拋到別的時間，而且是分開的。
- **靈魂回到過去**：
  - 每當某一個未來的天終究塌下來，霽弦死在雲境，靈魂就被天缺拋回過去，落進**十五年前、剛住進青溪那間屋子的自己身上**；
  - 那個少年醒來，帶著模糊的、像夢一樣的「以後的記憶」，重新走一次；
  - 這就是一次「重來」。他已經重來過很多次，靈魂每過一次天缺就磨掉一點，最先磨掉的是在青溪的記憶。
- **肉體被拋到別的時代**：
  - 在某幾次重來裡，天缺撕開的時候，他是**連人帶身體**被捲出去的，掉進另一個年代，帶著當時的靈魂和記憶，回不去；
  - 一個時代裡可以同時有兩個霽弦：被綁在雲境的那一個，和從別的時間掉進來的那一個；
  - 掉進來的那一個戴著面具：一是不能讓人認出同一張臉，二是在他的經驗裡，見到「以前的自己」的人，那一次都會變得更糟。

他在各個年代留下的痕跡（玩家一路聽到「戴面具的旅人」的傳說，最後才知道全是他）：
| 年代 | 戴面具的人做了什麼 | 玩家在哪裡聽到 |
|---|---|---|
| 六十年前，戊辰年 | 天裂那一夜，把那位女子封在缺月裡的嬰兒抱到寒漪宮，沉進冰湖。在他經歷過的未來裡，小滿是撐住結局的那個人，所以他得讓她活到今年 | 寒漪宮：守湖的老婆婆記得那晚有個戴面具的人走上冰面，記不得臉 |
| 約四十年前，祇苑 | 把被判的弟弟從雷院救出來，替他換了名字（「弟弟被人救下」） | 祇苑：女判官的弟弟遺物裡有一張面具的畫 |
| 約十五年前，青溪 | 把那片戊辰年的瓦埋在那間屋子後面，讓十五歲的自己一定會翻到。這片瓦是一個圈：他翻到瓦，才走上這條路；走到最後，他才回去埋瓦 | 九夜揭開 |

  - 他的靈魂過了太多次天缺，在青溪的記憶已經沒了。他站在那間空屋前，看著田裡的作物：「我好像……在這裡住過。」玩家可以回：「歡迎回來。」

## 十一、缺月：她，和天上的守夜人（第四版）〔新〕

z1nnz 2026-10-31：選方案 A、B、D、E 合在一起，可以分成好幾條故事，不一定全部都是缺月的故事；靈氣的設定不採用。

### 這幾條線怎麼分
| 故事線 | 用的方案 | 感覺 |
|---|---|---|
| 一、她（主線最深處） | A 欠她的債 + B 月亮就是她 | 沉重、虧欠 |
| 二、天上的守夜人（歷代承天者） | D 還沒換崗的先鋒 + E 被忘記的人 | 悲壯、意難平 |
| 三、七個同學與茶亭 | 不用缺月 | 友情、等待、和解 |
| 四、青溪同屆五人 | 不用缺月 | 青春、離散 |
| 五、七地的家人故事 | 不用缺月 | 每一地一種感覺 |
| 終章 | 四個一起收 | 大家一起扛 |

### 一、她（A + B）
- **三千年前**：第一個飛升的人上天，帶不走自己那一份天，天往下塌，沒有人敢去扛。他的女兒把**所有人**的那一份都接到自己身上，一個人上了天，化成**月亮**。
- **人人都有缺月**：缺月就是**她替你扛著的那一份**留下的缺口。所有人都欠她，而且所有人都忘了。
- **月亮從沒圓過，三千年來一直在變瘦**：她一個人扛不動全部，一點一點在耗。之後每一個飛升的人，又把自己那一份丟給她，那一夜月亮會肉眼可見地少一片。
- **她沒有名字**：她是第一個被所有人忘記的人（見下一條線的規矩）。只有童謠還唱「月圓那天，大家回家」。
- **伏筆**：
  - 博古架、各宗藏的古畫：越古老的畫，月亮越圓；
  - 飛升慶典那一夜，天上的月亮少一片，可是所有人都在看煙火；
  - 天缺另一邊，第一個飛升的人三千年來一直往下撐，因為他知道是誰在下面替他扛。

### 二、天上的守夜人（D + E）
- **千年前**：她快撐不住了。先人立大陣，**每一代送一個人上去，站到她身邊一起扛**。這就是「一人承天」。上去的人沒有死，三千年來都還站在天上，排成一列，最新的一個站在最前面、扛最多。
- **被忘記（E）**：
  - 上去的人，會被地上**所有人**忘記，因為還被記著的人，會被牽掛拉回地上，天就會晃。這是天的規矩，不是誰下的咒；
  - 名字寫在紙上，也會一年一年淡掉。太玄名冊上霽弦的名字，墨淡得不正常；
  - 所以三千年來，**沒有人知道上面有人**，也就從來沒有人去換崗（D）。他們等了三千年，不是因為沒人願意去，是因為沒人記得。
- **人人心裡都有一個想不起的人**：每個家族都送過一個人上去，被忘了。每個人都說不出自己少了什麼，可是都少了。
- **缺月深 = 心裡那個洞最大**：
  - 洞大的人會開始「想起來」；一想起來，上面那個人就會被拉一下，天就會晃；
  - 太玄帶走缺月深的人，一是怕他們想起來，二是洞最大的人最撐得住，最適合下一個上去。
- **寒漪宮**：全天下唯一在努力記住守夜人的地方。每有一個人上去，冬至就在冰上刻名字，趁還沒忘之前。可是刻下去的字也會淡，最底下的都看不清了；戊辰年那一格來不及刻，只留下「所謂伊人」。
- **民間說法**：「缺角亮一下」：月亮缺的那一角偶爾閃一下光，老人說是有人走了。其實是又有一個人上去了，也是又有一個人被忘了。

**每一個人的那一條線**
| 人 | 怎麼上去、怎麼被忘 | 感覺 |
|---|---|---|
| 師父 | 十年前上去，七個同學忘了他，只覺得心裡空了一塊。斷脈之夜天塌，他從那一列掉下來，七人在青溪看見他的臉，才全部想起來，然後要親手斬他 | 三百年的悔 |
| 戊辰年那位女子 | 瓦上、冰湖上都沒有她的名字。她把嬰兒封進缺月以後才上去 | 所謂伊人 |
| 小滿 | 心裡的洞是母親，所以最深。她從來不知道自己少的是誰 | 意難平 |
| 柳知微 | 把孩子們的洞藏起來，不讓大陣看見。她上去以後，沈岳也忘了她，可是每晚還是去點那盞燈，不知道點給誰 | 沒說出口的愛 |
| 霽弦 | 青溪忘了他，只剩一封沒署名的信、一個墨淡掉的名字 | 被等待的人 |

### 只有玩家記得〔新〕
- 柳知微上去的那一刻，遊戲世界裡的所有 NPC 都忘了她：
  - 村民的對話裡再也不提她；
  - 玩家的遊歷手札裡，寫著她的那幾頁，字一天一天淡掉。
- 可是**玩家本人記得**。坐在螢幕前的那個人，和她一起過了新手篇的十天。
- 全世界只有玩家記得她，這是「只有一個人記得」用在全服身上。玩家去跟沈岳說「你在等一個叫柳知微的人」，沈岳會停很久：「……我不認識這個名字。可是你說的時候，我這裡很痛。」
- 終章能把守夜人一個一個叫回來，靠的就是這件事：天上的人被所有人忘了，只有玩家一直記得，可以替他們喊出名字。

### 終章：四條線一起收
1. 霽弦撐不住，第一次開口求救。
2. 全服一起回應，每個人把**她替你扛著的那一份接回自己身上**（A）。天由所有人一起撐。
3. 天上的守夜人不用再站了。三千年的人一個一個走下來，終於有人來換崗（D）。
4. 每走下來一個人，地上就有人**想起他的名字**（E）：
   - 寒漪宮冰湖的空格浮出名字，戊辰年那一格，是小滿想起的母親的名字；
   - 七個同學想起師父年輕時的樣子；
   - 沈岳想起了柳知微。
5. 最後走下來的是她。月亮第一次圓了（B）。天缺另一邊，第一個飛升的人終於見到女兒。

**留一件回不來的事**：上面的人也會忘記地上的人。柳知微走下來，沈岳想起了她，**她卻不記得他**。那盞燈，他還在點。

### 和其他設定的接法
- **天壓**：上去的人越扛越吃力，天越重，所以每次有人飛升（把自己那一份丟給她），天壓就重一點。
- **測資台的裂光**：心裡的洞很大的人一放上去，紋路就閃一道月牙形的光。
- **霽弦的穿越**：站在最前面的守夜人碰得到天缺，天缺在時間之外，所以他的靈魂與肉體都可能被拋到別的時間（第六節）。被他在過去救過的人，也一個一個忘了他，只記得「一個戴面具的人」。
- **斷章**：斷脈之夜的記載是小師妹撕的（第四節）。更早的那些空白，是守夜人的年代：那些人被忘了，所以歷史也跟著空了。
