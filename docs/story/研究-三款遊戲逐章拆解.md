# 研究：原神、崩壞：星穹鐵道、鳴潮逐章拆解

> 2026-11-01，Claude Code。研究方案步驟 1、2（`故事研究方案-2026-11-01.md`）。
> 只拆**結構與手法**，不照搬情節。章節名稱與細節依公開的百科、玩家整理與記憶彙整，個別譯名、版本歸屬可能有出入，以官方為準；重點是每一章「怎麼做」。

每一章用同一張表：開場、主角想要什麼、地區之神、對手、轉折、揭開了什麼、留下的伏筆、基調、讓人記得的一句（或一個畫面）。

## 一、原神（魔神任務）

### 序章・蒙德（自由）
| 項目 | 內容 |
|---|---|
| 開場 | 雙子被未知的神攔下，一人被封印，旅行者醒在異世界，撿到派蒙 |
| 主角想要 | 找回失散的血親（整部主線的動力） |
| 地區之神 | 風神，以吟遊詩人的樣子混在人群裡 |
| 對手 | 被深淵教團汙染、受傷的風龍；愚人眾執行官女士 |
| 轉折 | 吟遊詩人就是風神本人；風龍不是壞，是受了傷、被利用 |
| 揭開 | 七神各自守一個國家；愚人眾在收集神之心 |
| 伏筆 | 深淵教團與血親的關係；風神用的樣子是一位死去的少年 |
| 基調 | 輕鬆、明亮、自由 |
| 記得的 | 被救的龍、在風裡唱歌的詩人 |

### 第一章・璃月（契約）
| 項目 | 內容 |
|---|---|
| 開場 | 請仙典儀上，岩神從天上墜落「死了」 |
| 地區之神 | 岩神，化身成往生堂的客卿，陪旅行者一起辦自己的葬禮 |
| 對手 | 愚人眾執行官公子，喚醒上古魔神 |
| 轉折 | 神沒有死，是自己安排的退休：把國家交給凡人的契約 |
| 揭開 | 神的時代正在結束，凡人要自己承擔 |
| 伏筆 | 魔神戰爭、坎瑞亞、層岩巨淵 |
| 基調 | 群像（七星、仙人、凡人一起撐住城） |
| 記得的 | 全城的人一起扛住魔神，神在旁邊看著，放心了 |

### 間章（璃月之後、須彌之前）
- 層岩巨淵：坎瑞亞與五百年前的災難；血親站在深淵那邊。
- **手法**：國與國之間，放「跨國的大祕密」與主角私人線，不屬於任何一國。

### 第二章・稻妻（永恆）
| 項目 | 內容 |
|---|---|
| 開場 | 鎖國、眼狩令，神收走人民的神之眼 |
| 地區之神 | 雷神，把自己封進心境，讓人偶代替她統治 |
| 對手 | 愚人眾執行官散兵；幕府內部的貪腐 |
| 轉折 | 神追求「永恆」，是因為失去了雙胞胎姐姐和好友，怕再失去 |
| 揭開 | 神也會因為悲傷做錯；凡人的願望才是永恆 |
| 伏筆 | 散兵的身世（第三章才用到） |
| 基調 | 衝突、壓迫、反抗 |
| 記得的 | 凡人的願望一起擋下神的一刀 |

### 第三章・須彌（智慧）
| 項目 | 內容 |
|---|---|
| 開場 | 夢境輪迴，同一天重複，所有人都不知道 |
| 地區之神 | 小吉祥草王，被關了五百年，被說成沒用 |
| 對手 | 教令院賢者、執行官博士；散兵被造成新神 |
| 轉折 | 前一任大慈樹王為了救世界，把自己從所有人的記憶裡抹掉；小草王是她留下的最後一片 |
| 揭開 | 世界樹記錄一切，也能被改寫；散兵把自己從歷史裡抹掉 |
| 伏筆 | 天理、世界被改寫過 |
| 基調 | 認知反轉：大家以為知道的，都是被改過的 |
| 記得的 | 被抹掉記憶的大慈樹王；小草王說「我是她留下的人」那種感覺 |

### 第四章・楓丹（正義）
| 項目 | 內容 |
|---|---|
| 開場 | 歌劇院審判、預言：所有人會溶解在水裡 |
| 地區之神 | 水神芙寧娜，五百年對所有人演戲 |
| 對手 | 預言本身；執行官僕人 |
| 轉折 | 芙寧娜是凡人，神的本體為了騙過天理，把神格分出去，讓她一個人演五百年 |
| 揭開 | 原始胎海、水龍才是真正的審判者 |
| 伏筆 | 天理的規則可以被欺騙 |
| 基調 | 閉環：前面每一個浮誇的細節，最後都換了意思 |
| 記得的 | 「罪人舞步旋」；孩子哄龍的歌「水龍水龍別哭了」；芙寧娜一個人坐在空蕩的劇場 |

### 第五章以後・納塔（戰爭）與更北
- 納塔：以名字、記憶、輪迴的英靈為核心；戰爭之國，所有人輪流為國家而死，再被記住。
- 之後走向至冬（愚人眾的國家）與天空島（天理）。
- **手法**：最後幾國才碰「整個世界的規則」，前面每一國都在為它鋪路。

### 原神的節奏
| 位置 | 做什麼 |
|---|---|
| 第一國 | 輕鬆、建立世界的規則（七神、愚人眾、深淵） |
| 第二國 | 群像，讓凡人站出來；第一次暗示神的時代會結束 |
| 間章 | 跨國的大祕密、主角私人線 |
| 中段每一國 | 每國翻一次「神為什麼這樣做」 |
| 中後段 | 開始碰「世界被改寫過」 |
| 最後 | 天理、天空島 |

**每一國都有**：一位藏著重擔的神 + 一位執行官 + 一個凡人的故事 + 一個「原來如此」的翻轉 + 一句讓人記得的話。

## 二、崩壞：星穹鐵道（開拓任務）

### 空間站・序章
- 開拓者被星核獵手放進一顆星核，醒來失憶。被列車組撿走。
- **手法**：主角身體裡就有主線的核心道具（星核），身世是一路的謎。

### 雅利洛-VI（保存／毀滅）
| 項目 | 內容 |
|---|---|
| 開場 | 冰封的星球，上層城市封鎖下層的人 |
| 地區的「神」 | 守護者可可利亞，看似為城犧牲，其實早被星核侵蝕 |
| 對手 | 被星核和「毀滅」引誘的可可利亞 |
| 轉折 | 守護者的女兒布洛妮婭要和母親為敵；上下層的人第一次合作 |
| 揭開 | 星核會帶來災難；星神的力量在宇宙各處 |
| 基調 | 階級、母女、冰封後的春天 |

### 仙舟羅浮（巡獵／豐饒）
| 項目 | 內容 |
|---|---|
| 開場 | 長生種的艦隊，追殺「豐饒」的長生災禍 |
| 地區的「神」 | 將軍景元；前世的飲月君（丹恆的過去） |
| 對手 | 藥王秘傳、幻朧；長生帶來的「魔陰身」 |
| 轉折 | 丹恆的前世是罪人；長生是詛咒 |
| 揭開 | 不同星神的信念互相衝突（巡獵追殺豐饒） |
| 基調 | 東方、宿命、前世今生 |

### 匹諾康尼（同諧／秩序／死亡）
| 項目 | 內容 |
|---|---|
| 開場 | 夢境之城的盛會，有人「死在夢裡」 |
| 地區的「神」 | 家族的星期日：想用秩序的美夢讓所有人不再受苦 |
| 對手 | 星期日（有信念的反派）；流螢與星核獵手的劇本 |
| 轉折 | 星期日相信自己是在拯救大家；主角團一度落敗，被捲進美夢 |
| 揭開 | 「劇本」在暗處推動；美夢與現實的取捨 |
| 基調 | 華麗、懸疑、浪漫（流螢：約好在夢裡重逢） |
| 記得的 | 「要在現實裡活下去」；流螢的約定 |

### 翁法羅斯（智識／記憶／毀滅）
| 項目 | 內容 |
|---|---|
| 開場 | 一個被藏在深空的世界，十二泰坦、黃金裔逐火 |
| 地區的「神」 | 十二泰坦；繼承泰坦權柄的黃金裔，各擔一份 |
| 對手 | 輪迴本身；被設計來催生毀滅的實驗 |
| 轉折 | 整個世界是一個演算的輪迴，三千萬次失敗；有一個人記得每一次 |
| 揭開 | 昔漣為穩定時間線犧牲自己；黃金裔一個一個交出權柄 |
| 基調 | 群像、史詩、輪迴的絕望與希望 |
| 記得的 | 每一位黃金裔都有一句代表自己的話；緹寶的「明天見」 |

### 星穹鐵道的節奏
- 每個世界自己完整，一段一段像單元劇；列車組（找到的家人）把它們串起來。
- 星神與命途是「信念的地圖」：每個世界的衝突，就是兩種信念的衝突。
- 主角身世（星核、劇本）在背景慢慢推進。
- 大篇章（翁法羅斯）用很長的篇幅做群像與輪迴，最後一起收。

## 三、鳴潮（主線）

### 今州（瑝瓏・第一章）
| 項目 | 內容 |
|---|---|
| 開場 | 漂泊者失憶醒來，世界經歷過一場災難「悲鳴」 |
| 主角想要 | 找回自己是誰 |
| 地區之神 | 歲主「角」，與令尹今汐共鳴；今汐是被角救活的嬰兒 |
| 對手 | 殘星會（有人類的臉、在做人工共鳴） |
| 轉折 | 守城的人與歲主的關係；殘星會讓時間失控，逼今汐提前面對繼承 |
| 揭開 | 歲主與共鳴者；漂泊者和世界最根本的事件有關 |
| 基調 | 東方、守城、傳承 |

### 黎那汐塔（第二章）
| 項目 | 內容 |
|---|---|
| 開場 | 守岸人的訊息，去找歲主英白拉多 |
| 地區之神 | 歲主英白拉多；聖女卡提希婭（芙露德莉斯）與歲主再度共鳴 |
| 對手 | 殘星會；隱海修會內部 |
| 轉折 | 卡提希婭的兩個身分；狂歡節提升信仰的真正目的 |
| 揭開 | 鳴式的終極目標是「天國」（黑潮的最終形態） |
| 基調 | 西方、信仰、狂歡與悲劇 |

### 七丘與之後
- 七丘：英雄選拔、不同維度的人物。
- 之後走向拉海洛等地；主角身世與聲骸的祕密逐步揭開。

### 鳴潮的節奏
- 主角身世是最大的謎，每一章給一點。
- 每一地：一位歲主 + 一位與祂共鳴的人（神與人的羈絆）+ 殘星會的幹部。
- 終極的宇宙威脅（鳴式、黑潮）在背景越來越大。

## 四、歸納：共同骨架（研究方案步驟 2）

| # | 骨架 | 為什麼撐得住好幾年 |
|---|---|---|
| 1 | **主角私人線**（血親、星核、身世） | 每一章玩家都有一個「我」想要的東西，地區換了，動力不斷 |
| 2 | **每個地區一位「神」，藏一個重擔** | 每一章的故事就是揭開這個人；神不同，感覺就不同 |
| 3 | **一個跨地區的組織，每地一位幹部，動機晚揭開** | 地區之間有連續的對手；幹部一個一個翻轉 |
| 4 | **深埋的歷史災難，放在間章** | 國與國之間有東西推進；歷史越挖越深 |
| 5 | **宇宙層的真相，留到最後幾章** | 給玩家長期的「為什麼」 |
| 6 | **每個地區自己完整、基調不同** | 單元劇式，新玩家也看得懂；老玩家看得到串聯 |
| 7 | **一路的同伴，本身也是謎** | 情感的錨；最後的告別最痛 |
| 8 | **支線比主線還感人** | 世界任務、傳說任務撐起「世界很大」 |
| 9 | **讓人記得住的句子與畫面** | 玩家會在社群裡一直傳 |
| 10 | **群像大篇章**（翁法羅斯） | 幾年一次，把很多人的線一起收，製造最大的情緒高峰 |

### 節奏（每一章揭開什麼）
| 位置 | 原神 | 星穹鐵道 | 鳴潮 | 《承天》該怎麼排 |
|---|---|---|---|---|
| 第一章 | 建立規則、輕鬆 | 主角身世起點 | 失憶醒來 | 青溪：溫暖、日常，只留怪事 |
| 第二章 | 群像、神的退場 | 單元劇 | 第一位歲主 | 宗門：歸屬，第一次懷疑（柳知微） |
| 間章 | 跨國祕密 | 劇本 | — | 歷史年代 |
| 中段 | 每國翻一次 | 每個世界一種信念 | 每地一位歲主 | 七地：每地一位守柱者、一位使者、一次翻轉 |
| 後段 | 世界被改寫過 | 群像大篇章 | 終極威脅浮現 | 九夜翻轉、長夜之境 |
| 最後 | 天理 | — | — | 雲境、承天 |

**結論**：v8 初稿補上的主角線、同伴、七位守柱者、登天會七使、間章，正好就是這三款共同骨架裡我們缺的。研究方案下一步（步驟 3）：拆小說與動畫的感動手法；步驟 4：把 z1nnz 的 60 多條想法放進骨架。
