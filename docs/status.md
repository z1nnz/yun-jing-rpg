# 目前狀態

更新：2026-10-26。專案仍在 M0／M1 原型階段。

## 已完成並有測試

- NestJS API、PGlite 本機持久化及本機驗證頁。
- 創角與出生在同一交易完成；並行請求只產生一份先天紀錄。
- 十個現實日測資門檻由服務端時間判定；測資前不公開完整先天。
- 採集、種植、採收、煉製、商店、兩宗基礎師承、共同工程和帳本原型。
- requestId 冪等、綁定物品、登入交接、PKCE 邊界、單次區域票證及靈草接收方原型。
- 山兔掉落／出售的服務端原型：內部死亡收據、同一出生唯一結算、短效商販距離授權、未綁定材料出售與帳本記錄。
- API 與持久化自動測試 53 項通過；狩獵整合契約見 [青溪採獵](qingxi-hunt-integration.md)。
- Multer 固定為 2.5.0；`npm audit --omit=dev --audit-level=high` 無高風險項目。

## 有原始碼但未完成驗證

- Unity 青溪灰盒、角色、輸入、鏡頭、FishNet 預測／校正與 30 Hz 專用程序。
- Windows、Android、Linux Server 建置腳本。
- Firebase 登入橋接、外部 PostgreSQL、跨 App 完整輸送流程。

本機有 Unity `6000.0.82f1`。本次整合嘗試遭 Editor 授權代碼 198 阻擋；協作者在另一部電腦以 `6000.0.85f1` 跑過青溪世界的套件匯入、編譯及路線測試，但批次結束時發生 `MonoManager NULL` 崩潰（exit 21）。本次合併後的 Unity 原始碼、FishNet 雙端連線、prefab、玩家建置與手機效能未在這台電腦通過。使用者目前指定先做 PWA 驗證，不再以 Unity 測試作為本輪關卡。[合併紀錄](integration-2026-10-26.md)。
